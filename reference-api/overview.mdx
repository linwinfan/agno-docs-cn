欢迎使用 Agno AgentOS API 的全面 API 参考文档。这个 RESTful API 使您能够以编程方式与您的 AgentOS 实例进行交互，管理智能体、团队和工作流，并将 AgentOS 功能集成到您的应用程序中。

## 认证

AgentOS 通过单一安全密钥支持 Bearer Token 认证。

- 当服务器上设置了 `OS_SECURITY_KEY` 环境变量时，所有路由都需要：

```bash
Authorization: Bearer <OS_SECURITY_KEY>
```

- 当未设置 `OS_SECURITY_KEY` 时，该实例的认证将被禁用。

请参阅专门指南：[使用安全密钥保护您的 AgentOS](/agent-os/security)。
