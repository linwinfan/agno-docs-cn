此示例展示如何为您的 agno 智能体添加检测并将跟踪信息发送到 LangWatch。

## 代码

```python cookbook/13_integrations/observability/langwatch_op.py
import langwatch
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools
from openinference.instrumentation.agno import AgnoInstrumentor

# 初始化 LangWatch 并检测 Agno
langwatch.setup(instrumentors=[AgnoInstrumentor()])

# 创建并配置您的 Agno 智能体
agent = Agent(
    name="股票价格智能体",
    model=OpenAIChat(id="gpt-5-mini"),
    tools=[DuckDuckGoTools()],
    instructions="您是一个互联网搜索智能体。查找并提供任何主题的准确信息。",
    debug_mode=True,
)

agent.print_response("What are the latest developments in artificial intelligence?")

```
