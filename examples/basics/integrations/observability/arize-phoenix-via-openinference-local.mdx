---
title: 通过 OpenInference 使用 Arize Phoenix（本地收集器）
---


## 概述

此示例演示如何使用 OpenInference 为您的 Agno 智能体添加检测并将跟踪信息发送到本地 Arize Phoenix 收集器。

## 代码

```python
import os

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools
from phoenix.otel import register

# 设置 Arize Phoenix 本地收集器端点
os.environ["PHOENIX_COLLECTOR_ENDPOINT"] = "http://localhost:6006"

# 配置 Phoenix 追踪器
tracer_provider = register(
    project_name="agno-stock-price-agent",  # 默认为 'default'
    auto_instrument=True,  # 自动使用已安装的 OpenInference 检测
)

# 创建并配置智能体
agent = Agent(
    name="股票价格智能体",
    model=OpenAIChat(id="gpt-5-mini"),
    tools=[DuckDuckGoTools()],
    instructions="您是一个互联网搜索智能体。查找并提供任何主题的准确信息。",
    debug_mode=True,
)

# 使用智能体
agent.print_response("What are the latest developments in artificial intelligence?")
```

## 用法

    </CodeGroup>
  </Step>
</Steps>
