## 概述

此示例演示如何使用 Weights & Biases (WandB) 的 Weave 来记录您的 Agno 智能体的模型调用。

## 代码

```python
import weave
from agno.agent import Agent
from agno.models.openai import OpenAIChat

# 创建并配置智能体
agent = Agent(model=OpenAIChat(id="gpt-5-mini"), markdown=True, debug_mode=True)

# 使用您的项目名称初始化 Weave
weave.init("agno")

# 定义一个运行智能体的函数，并使用 weave.op() 装饰器
@weave.op()
def run(content: str):
    return agent.run(content)

# 使用该函数记录模型调用
run("Share a 2 sentence horror story")
```

## 用法

<Steps>
  <Step title="安装 Weave">
    ```bash
    pip install agno openai weave
    ```
  </Step>

  <Step title="使用 WandB 进行身份验证">
    - 访问 [WandB](https://wandb.ai) 并从 [此处](https://wandb.ai/authorize) 复制您的 API 密钥。
    - 在终端提示时输入您的 API 密钥，或将其导出为环境变量：
    ```bash
    export WANDB_API_KEY=<your-api-key>
    ```
  </Step>

  <Step title="运行智能体">
    <CodeGroup>
    ```bash Mac
    python cookbook/observability/weave_op.py
    ```

    ```bash Windows
    python cookbook/observability/weave_op.py
    ```
    </CodeGroup>
  </Step>
</Steps>

## 注意事项

- **初始化**: 调用 `weave.init("project-name")` 使用您的项目名称初始化 Weave。
- **装饰器**: 使用 `@weave.op()` 装饰您想要用 Weave 记录的函数。
