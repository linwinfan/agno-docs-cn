## 代码

```python cookbook/14_tools/yfinance_tools.py
from agno.agent import Agent
from agno.tools.yfinance import YFinanceTools

agent = Agent(
    tools=[YFinanceTools()],
        markdown=True,
)
agent.print_response("Get the current stock price and recent history for AAPL")
```
