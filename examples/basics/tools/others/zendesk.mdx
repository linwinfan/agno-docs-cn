## 代码

```python cookbook/14_tools/zendesk_tools.py
from agno.agent import Agent
from agno.tools.zendesk import ZendeskTools

agent = Agent(
    tools=[ZendeskTools()],
        markdown=True,
)
agent.print_response("Show me all open tickets")
```
