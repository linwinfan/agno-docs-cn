## 代码

```python cookbook/14_tools/calcom_tools.py
from datetime import datetime

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.calcom import CalComTools

agent = Agent(
    name="Calendar Assistant",
    instructions=[
        f"您是日程安排助手。今天是 {datetime.now()}.",
        "您可以通过以下方式帮助用户：",
        "    - 查找可用时间段",
        "    - 创建新预订",
        "    - 管理现有预订（查看、重新安排、取消）",
        "    - 获取预订详情",
        "    - 重要提示：在重新安排或取消预订时，请调用 get_upcoming_bookings 函数获取预订uid。在为给定时间创建预订之前，请检查可用时段",
        "在进行预订或更改之前，请始终确认重要细节。",
    ],
    model=OpenAIChat(id="gpt-4"),
    tools=[CalComTools(user_timezone="America/New_York")],
        markdown=True,
)

agent.print_response("What are my bookings for tomorrow?")
```
