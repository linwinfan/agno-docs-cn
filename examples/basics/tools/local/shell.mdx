## 代码

```python cookbook/14_tools/shell_tools.py
from agno.agent import Agent
from agno.tools.shell import ShellTools

agent = Agent(
    tools=[ShellTools()],
        markdown=True,
)
agent.print_response("列出当前目录中的所有文件")
```
