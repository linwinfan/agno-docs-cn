## 代码

```python cookbook/14_tools/local_file_system_tools.py
from agno.agent import Agent
from agno.tools.local_file_system import LocalFileSystemTools

agent = Agent(
    instructions=[
        "您是一个文件管理助手，帮助将内容保存到本地文件",
        "使用适当的名称和扩展名创建文件",
        "在指定的目录结构中组织文件",
    ],
    tools=[LocalFileSystemTools(target_directory="./output")],
    markdown=True,
)

agent.print_response("将此会议摘要保存到文件中：'讨论了第四季度目标和预算分配'")
```
