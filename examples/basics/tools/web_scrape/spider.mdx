## 代码

```python cookbook/14_tools/spider_tools.py
from agno.agent import Agent
from agno.tools.spider import SpiderTools

agent = Agent(
    tools=[SpiderTools()],
        markdown=True,
)
agent.print_response("Crawl https://example.com and extract all links")
```
