## 代码

```python cookbook/14_tools/whatsapp_tools.py
from agno.agent import Agent
from agno.models.google import Gemini
from agno.tools.whatsapp import WhatsAppTools

agent = Agent(
    name="whatsapp",
    model=Gemini(id="gemini-2.0-flash"),
    tools=[WhatsAppTools()],
)

# 示例：发送模板消息
# 注意：将'''hello_world'''替换为您实际的模板名称
agent.print_response(
    "使用英文的'''hello_world'''模板向+91 1234567890发送模板消息"
)
```

## 用法

<Steps>
  <Snippet file="create-venv-step.mdx" />

  <Step title="设置WhatsApp Business API">
    1. 前往 [Meta for Developers](https://developers.facebook.com/docs/whatsapp/cloud-api/get-started)
    2. 创建Meta应用并设置WhatsApp Business API。
    3. 获取您的电话号码ID和永久系统用户访问令牌。
  </Step>

  <Step title="设置您的API密钥和标识符">
    ```bash
    export WHATSAPP_ACCESS_TOKEN=xxx
    export WHATSAPP_PHONE_NUMBER_ID=xxx
    export OPENAI_API_KEY=xxx # 或您首选的LLM API密钥
    ```
  </Step>

  <Step title="安装库">
    ```bash
    pip install -U agno openai google-generativeai # 添加任何其他必要的WhatsApp SDK
    ```
  </Step>

  <Step title="运行代理">
    <CodeGroup>
    ```bash Mac
    python cookbook/14_tools/whatsapp_tools.py
    ```

    ```bash Windows
    python cookbook/14_tools/whatsapp_tools.py
    ```
    </CodeGroup>
  </Step>
</Steps>
