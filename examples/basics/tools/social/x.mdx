## 代码

```python cookbook/14_tools/x_tools.py
from agno.agent import Agent
from agno.tools.x import XTools

agent = Agent(
    tools=[XTools()],
        markdown=True,
)
agent.print_response("Make a post saying 'Hello World from Agno!'")
```
