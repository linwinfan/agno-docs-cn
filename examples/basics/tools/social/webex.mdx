## 代码

```python cookbook/14_tools/webex_tools.py
from agno.agent import Agent
from agno.tools.webex import WebexTools

agent = Agent(
    name="Webex Assistant",
    tools=[WebexTools()],
    description="您是一个可以发送消息和管理空间的Webex助手。",
    instructions=[
        "您可以通过以下方式帮助用户：",
        "- 列出可用的Webex空间",
        "- 向空间发送消息",
        "在发送消息之前始终确认空间存在。",
    ],
        markdown=True,
)

# 列出Webex中的所有空间
agent.print_response("列出我们Webex上的所有空间", markdown=True)

# 向Webex中的空间发送消息
agent.print_response(
    "向webex欢迎空间发送一条有趣的破冰消息", markdown=True
)
```

## 用法

<Steps>
  <Snippet file="create-venv-step.mdx" />

  <Step title="设置Webex机器人">
    1. 前往 [Webex开发者门户](https://developer.webex.com/)
    2. 创建机器人：
       - 导航到我的Webex应用 → 创建机器人
       - 填写机器人详细信息并点击添加机器人
    3. 获取您的访问令牌：
       - 复制机器人创建后显示的令牌
       - 或通过我的Webex应用 → 编辑机器人重新生成
  </Step>

  <Step title="设置您的API密钥">
    ```bash
    export WEBEX_ACCESS_TOKEN=xxx
    export OPENAI_API_KEY=xxx
    ```
  </Step>

  <Step title="安装库">
    ```bash
    pip install -U webexpythonsdk openai agno
    ```
  </Step>

  <Step title="运行代理">
    <CodeGroup>
    ```bash Mac
    python cookbook/14_tools/webex_tools.py
    ```

    ```bash Windows
    python cookbook/14_tools/webex_tools.py
    ```
    </CodeGroup>
  </Step>
</Steps>
