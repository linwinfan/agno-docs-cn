## 代码

```python cookbook/14_tools/googlesearch_tools.py
from agno.agent import Agent
from agno.tools.duckduckgo import DuckDuckGoTools

agent = Agent(
    tools=[DuckDuckGoTools()],
        markdown=True,
)
agent.print_response("AI领域有哪些最新发展？")
```
