## 代码

```python cookbook/14_tools/valyu_tools.py
from agno.agent import Agent
from agno.tools.valyu import ValyuTools

agent = Agent(
    instructions=[
        "您是一个帮助查找学术论文和网络内容的研究助手",
        "使用 Valyu 搜索高质量、相关的信息",
        "提供带有相关性评分的搜索结果详细分析",
    ],
    tools=[ValyuTools()],
    markdown=True,
)

agent.print_response("查找关于医疗保健中机器学习的最新研究论文")
```
