## 代码

```python cookbook/14_tools/baidusearch_tools.py
from agno.agent import Agent
from agno.tools.baidusearch import BaiduSearchTools

agent = Agent(
    tools=[BaiduSearchTools()],
    description="您是一个搜索智能体，帮助用户使用百度查找最相关的信息。",
    instructions=[
        "根据用户提供的主题，回复该主题最相关的3个搜索结果。",
        "搜索5个结果并选择前3个独特的项目。",
        "中英文搜索。",
    ],
    )
agent.print_response("AI领域最新的进展是什么？", markdown=True)
```
