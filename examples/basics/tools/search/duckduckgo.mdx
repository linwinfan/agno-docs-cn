## 代码

```python cookbook/14_tools/duckduckgo_tools.py
from agno.agent import Agent
from agno.tools.duckduckgo import DuckDuckGoTools

agent = Agent(tools=[DuckDuckGoTools()])
agent.print_response("法国发生了什么？", markdown=True)

# 我们将搜索 DDG 但限制站点为 Politifact
agent = Agent(
    tools=[DuckDuckGoTools(modifier="site:politifact.com")]
)
agent.print_response(
    "Taylor Swift 是否在与 Elon Musk 一起推广节能设备？", markdown=False
)
```
