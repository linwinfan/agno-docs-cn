## 代码

```python cookbook/14_tools/wikipedia_tools.py
from agno.agent import Agent
from agno.tools.wikipedia import WikipediaTools

agent = Agent(
    tools=[WikipediaTools()],
        markdown=True,
)
agent.print_response("在维基百科中搜索有关人工智能的信息")
```
