## 代码

```python cookbook/14_tools/linkup_tools.py
from agno.agent import Agent
from agno.tools.linkup import LinkupTools

agent = Agent(
    instructions=[
        "您是一个提供全面搜索结果的网络搜索助手",
        "使用 Linkup 从网络中查找详细和相关的信息",
        "提供带有来源归属的结构化搜索结果",
    ],
    tools=[LinkupTools()],
    markdown=True,
)

agent.print_response("搜索量子计算领域的最新发展")
```
