## 代码

```python cookbook/14_tools/hackernews_tools.py
from agno.agent import Agent
from agno.tools.hackernews import HackerNewsTools

agent = Agent(
    tools=[HackerNewsTools()],
        markdown=True,
)
agent.print_response("目前 Hacker News 上的热门故事是什么？")
```
