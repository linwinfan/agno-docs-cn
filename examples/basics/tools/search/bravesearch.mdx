## 代码

```python cookbook/14_tools/bravesearch_tools.py
from agno.agent import Agent
from agno.tools.bravesearch import BraveSearchTools

agent = Agent(
    tools=[BraveSearchTools()],
    description="您是一个新闻智能体，帮助用户查找最新新闻。",
    instructions=[
        "根据用户提供的主题，回复该主题的4个最新新闻条目。"
    ],
    )
agent.print_response("AI智能体", markdown=True)
```
