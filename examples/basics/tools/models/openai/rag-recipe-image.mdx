---
title: 食谱 RAG 图像智能体
---


此示例演示一个多模态 RAG 智能体，该智能体使用 Groq 和 OpenAITools 来搜索 PDF 食谱知识库并为食谱生成逐步可视化指南。

## 代码

```python ref/recipe_rag_image.py
"""示例：多模态 RAG 与图像智能体

一个使用 Llama 4 进行多模态 RAG 和 OpenAITools 来创建食谱的可视化、分步图像手册的智能体。

运行: `pip install openai agno groq cohere` 来安装依赖项
"""

from pathlib import Path

from agno.agent import Agent
from agno.knowledge.embedder.cohere import CohereEmbedder
from agno.knowledge.knowledge import Knowledge
from agno.models.groq import Groq
from agno.tools.openai import OpenAITools
from agno.utils.media import download_image
from agno.vectordb.pgvector import PgVector

knowledge_base = Knowledge(
    vector_db=PgVector(
        db_url="postgresql+psycopg://ai:ai@localhost:5532/ai",
        table_name="embed_vision_documents",
        embedder=CohereEmbedder(
            id="embed-v4.0",
        ),
    ),
)

knowledge_base.add_content(
    url="https://agno-public.s3.amazonaws.com/recipes/ThaiRecipes.pdf"
)

agent = Agent(
    name="EmbedVisionRAGAgent",
    model=Groq(id="meta-llama/llama-4-scout-17b-16e-instruct"),
    tools=[OpenAITools()],
    knowledge=knowledge_base,
    instructions=[
        "您是专业的食谱助手。",
        "当被要求提供食谱时：",
        "1. 搜索知识库以检索相关食谱详细信息。",
        "2. 仔细分析检索到的食谱步骤。",
        "3. 使用 `generate_image` 工具为食谱创建可视化、分步的图像手册。",
        "4. 清晰地呈现食谱文本，并提及您已生成了配套的图像手册。在生成图像时添加说明。",
    ],
    markdown=True,
    debug_mode=True,
)

response = agent.print_response(
    "泰式咖喱的食谱是什么？",
)
if response.images:
    download_image(response.images[0].url, Path("tmp/recipe_image.png"))
```

## 用法
