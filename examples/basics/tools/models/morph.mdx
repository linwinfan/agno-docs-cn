## 代码

```python cookbook/14_tools/morph_tools.py
from agno.agent import Agent
from agno.tools.models.morph import MorphTools

agent = Agent(
    instructions=[
        "您是使用 Morph 高级 AI 功能的代码编辑助手",
        "帮助用户智能地修改、改进和重构代码",
        "在保持代码质量的同时高效应用代码更改",
    ],
    tools=[MorphTools()],
    markdown=True,
)

agent.print_response("重构此 Python 函数以提高效率并添加类型提示")
```
