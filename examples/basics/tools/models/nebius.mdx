## 代码

```python cookbook/14_tools/nebius_tools.py
from agno.agent import Agent
from agno.tools.models.nebius import NebiusTools

agent = Agent(
    instructions=[
        "您是使用 Nebius Token Factory 的 AI 图像生成助手",
        "根据用户描述创建高质量图像",
        "提供有关生成图像的详细信息",
    ],
    tools=[NebiusTools()],
    markdown=True,
)

agent.print_response("生成一张夕阳下有飞行汽车的未来城市图像")
```
