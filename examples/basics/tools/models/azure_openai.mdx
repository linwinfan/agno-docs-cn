## 代码

```python cookbook/14_tools/azure_openai_tools.py
from agno.agent import Agent
from agno.tools.models.azure_openai import AzureOpenAITools

agent = Agent(
    instructions=[
        "您是使用 Azure OpenAI 的 AI 图像生成助手",
        "根据用户描述生成高质量图像",
        "提供生成图像的详细描述",
    ],
    tools=[AzureOpenAITools()],
    markdown=True,
)

agent.print_response("生成一张山间日落的图像")
```
