title: Neo4j 工具

---


## 代码

```python cookbook/14_tools/neo4j_tools.py
from agno.agent import Agent
from agno.tools.neo4j import Neo4jTools

agent = Agent(
    instructions=[
        "你是帮助处理 Neo4j 操作的图数据库助手",
        "执行 Cypher 查询以分析图数据和关系",
        "提供有关图结构和模式的见解",
    ],
    tools=[Neo4jTools()],
    markdown=True,
)

agent.print_response("显示图数据库的模式并列出所有节点标签")
```
