## 代码

```python cookbook/14_tools/duckdb_tools.py
from agno.agent import Agent
from agno.tools.duckdb import DuckDbTools

agent = Agent(
    tools=[DuckDbTools()],
        instructions="使用此文件获取电影数据: https://agno-public.s3.amazonaws.com/demo_data/IMDB-Movie-Data.csv",
)
agent.print_response(
    "电影的平均评分是多少?", markdown=True, stream=False
)
```
