De脚本ion:

Implemented an AI 代理 using the agno 库 with PandasTools for automated data analysis.

The 代理 loads a CSV 文件 (data.csv) and performs analysis based on natural language 说明.

Enables interaction with data without manual Pandas coding, simplifying data exploration and insights extraction.

Includes setup 说明 for 环境 variables and 依赖项.

---
title: Pandas Tools
---

## 代码

```python cookbook/14_tools/pandas_tools.py
from agno.agent import Agent
from agno.tools.pandas import PandasTools

agent = Agent(
    tools=[PandasTools()],
        markdown=True,
)
agent.print_response("Load and analyze the dataset from data.csv")
```
