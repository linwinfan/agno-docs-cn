## 代码

```python cookbook/14_tools/sql_tools.py
from agno.agent import Agent
from agno.tools.sql import SQLTools

agent = Agent(
    tools=[SQLTools(db_url="sqlite:///database.db")],
        markdown=True,
)
agent.print_response("显示数据库中的所有表及其模式")
```
