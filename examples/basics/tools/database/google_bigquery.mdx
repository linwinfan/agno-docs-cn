## 代码

```python cookbook/14_tools/google_bigquery_tools.py
from agno.agent import Agent
from agno.tools.google_bigquery import GoogleBigQueryTools

agent = Agent(
    instructions=[
        "你是帮助处理 BigQuery 操作的数据分析师助手",
        "执行 SQL 查询以分析大型数据集",
        "提供查询结果的见解和摘要",
    ],
    tools=[GoogleBigQueryTools(dataset="your_dataset_name")],
    markdown=True,
)

agent.print_response("列出数据集中的所有表并描述销售表")
```
