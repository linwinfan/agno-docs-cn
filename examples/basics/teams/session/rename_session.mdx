---
title: 会话名称管理
---


此示例演示如何设置自定义会话名称或自动生成有意义的名称，以更好地组织和识别会话。

## 代码

```python cookbook/02_examples/teams/session/06_rename_session.py
from agno.agent.agent import Agent
from agno.db.postgres import PostgresDb
from agno.models.openai import OpenAIChat
from agno.team import Team

db_url = "postgresql+psycopg://ai:ai@localhost:5532/ai"

db = PostgresDb(db_url=db_url)

agent = Agent(
    model=OpenAIChat(id="gpt-5-mini"),
)

team = Team(
    model=OpenAIChat(id="gpt-5-mini"),
    members=[agent],
    db=db,
)

team.print_response("告诉我一个关于太空的有趣新事实")
team.set_session_name(session_name="有趣的太空事实")
print(team.get_session_name())

# 自动生成会话名称
team.set_session_name(autogenerate=True)
print(team.get_session_name())
```
