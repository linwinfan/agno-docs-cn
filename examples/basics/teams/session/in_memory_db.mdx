---
title: 内存数据库会话
---


此示例展示如何使用内存数据库与团队配合存储会话、用户记忆等，无需设置持久化数据库——适用于开发和测试。

## 代码

```python cookbook/02_examples/teams/session/07_in_memory_db.py
"""此示例展示如何使用内存数据库与团队配合。

通过这种方式，您可以在不设置数据库的情况下存储团队会话、用户记忆等。
请注意，在生产环境中建议使用数据库。
"""

from agno.agent import Agent
from agno.db.in_memory import InMemoryDb
from agno.models.openai import OpenAIChat
from agno.team import Team
from rich.pretty import pprint

# 设置内存数据库
db = InMemoryDb()

agent = Agent(
    model=OpenAIChat(id="gpt-5-mini"),
    name="Research Assistant",
)

team = Team(
    model=OpenAIChat(id="gpt-5-mini"),
    members=[agent],
    db=db,
    # 设置 add_history_to_context=true 以将之前的聊天历史添加到发送给模型的上下文中。
    add_history_to_context=True,
    # 要添加到消息中的历史响应数量。
    num_history_runs=3,
    session_id="test_session",
)

# -*- 创建一次运行
team.print_response("分享一个两句话的恐怖故事", stream=True)

# -*- 打印内存中的消息
print("\n" + "=" * 50)
print("第一次运行后的聊天历史")
print("=" * 50)
try:
    chat_history = team.get_chat_history(session_id="test_session")
    pprint([m.model_dump(include={"role", "content"}) for m in chat_history])
except Exception as e:
    print(f"Error getting chat history: {e}")
    print("在内存数据库的首次运行中，这可能是预期的行为")

# -*- 询问一个延续对话的后续问题
team.print_response("我的第一条消息是什么？", stream=True)

# -*- 打印内存中的消息
print("\n" + "=" * 50)
print("第二次运行后的聊天历史")
print("=" * 50)
try:
    chat_history = team.get_chat_history(session_id="test_session")
    pprint([m.model_dump(include={"role", "content"}) for m in chat_history])
except Exception as e:
    print(f"Error getting chat history: {e}")
    print("这表明内存数据库会话处理存在问题")
```
