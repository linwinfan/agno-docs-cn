---
title: 带引用的会话摘要
---


此示例演示如何使用带上下文引用的会话摘要，使代理能够维持对话上下文并引用之前的会话摘要。

## 代码

```python 04_session_summary_references.py
"""
此示例展示如何在代理配置中使用 `add_session_summary_to_context` 参数将
会话摘要添加到代理上下文中。

通过运行以下命令在本地 Docker 上启动 postgres 数据库：cookbook/scripts/run_pgvector.sh
"""

from agno.agent.agent import Agent
from agno.db.postgres import PostgresDb
from agno.models.openai import OpenAIChat

db_url = "postgresql+psycopg://ai:ai@localhost:5532/ai"

db = PostgresDb(db_url=db_url, session_table="sessions")

agent = Agent(
    model=OpenAIChat(id="gpt-5-mini"),
    db=db,
    session_id="session_summary",
    enable_session_summaries=True,
)

# 这将创建一个新的会话摘要
agent.print_response(
    "My name is John Doe and I like to hike in the mountains on weekends.",
)

# 您可以在不创建或更新任何新摘要的情况下使用会话存储中的现有会话摘要。
agent = Agent(
    model=OpenAIChat(id="gpt-5-mini"),
    db=db,
    session_id="session_summary",
    add_session_summary_to_context=True,
)

agent.print_response("I also like to play basketball.")

# 或者，您可以在不将会话摘要添加到上下文的情况下创建新的会话摘要。
```
