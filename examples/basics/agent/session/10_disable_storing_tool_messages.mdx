此示例展示如何在会话中禁用存储工具消息。

## 代码

```python disable_storing_tool_messages.py
"""
演示 store_tool_messages 选项的简单示例
"""

from agno.agent import Agent
from agno.db.sqlite import SqliteDb
from agno.models.openai import OpenAIChat
from agno.tools.hackernews import HackerNewsTools
from agno.utils.pprint import pprint_run_response

agent = Agent(
    model=OpenAIChat(id="gpt-4o-mini"),
    tools=[HackerNewsTools()],
    db=SqliteDb(db_file="tmp/example_no_tools.db"),
    store_tool_messages=False,  # 不存储工具执行详情
)

if __name__ == "__main__":
    print("\n运行带有工具的代理，但不存储工具结果...")
    response = agent.run("What is the latest news from Hacker News?")

    pprint_run_response(response)

    # 检查存储的内容
    stored_run = agent.get_last_run_output()
    if stored_run and stored_run.messages:
        tool_messages = [m for m in stored_run.messages if m.role == "tool"]
        print("\n 存储信息：")
        print(f"   存储的总消息数：{len(stored_run.messages)}")
        print(f"   工具结果消息数：{len(tool_messages)}（已清除！）")
```
