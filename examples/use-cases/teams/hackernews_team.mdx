构建一个聚合、策划和分析热门HackerNews故事的团队。此示例结合了多个专门代理来搜索主题、阅读文章并生成具有结构化输出的综合摘要。

## 您将学习的内容

通过构建此团队，您将理解：
- 如何集成多个数据源（HackerNews API、网络搜索、文章阅读器）
- 如何使用Pydantic模型定义结构化输出模式
- 如何协调具有特定说明的代理以处理复杂工作流
- 如何将实时数据与网络搜索结合进行全面分析

## 使用案例

构建新闻聚合平台、趋势分析系统、内容策划工具或自动化通讯生成器。

## 工作原理

团队协调三个专门代理创建详细的文章：

1. **发现**: HackerNews搜索器从HackerNews找到热门故事
2. **阅读**: 文章阅读器从故事URL提取完整内容
3. **搜索**: 网络搜索器查找额外的上下文和相关信息
4. **综合**: 团队将所有发现结合成带有摘要和引用的结构化文章

团队输出遵循定义模式的结构化数据，包含标题、摘要和参考链接。

## 代码

```python hackernews_team.py
from typing import List

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.team import Team
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.hackernews import HackerNewsTools
from agno.tools.newspaper4k import Newspaper4kTools
from pydantic import BaseModel


class Article(BaseModel):
    title: str
    summary: str
    reference_links: List[str]


hn_researcher = Agent(
    name="HackerNews Researcher",
    model=OpenAIChat(id="gpt-4o"),
    role="Gets top stories from hackernews.",
    tools=[HackerNewsTools()],
)

web_searcher = Agent(
    name="Web Searcher",
    model=OpenAIChat(id="gpt-4o"),
    role="Searches the web for information on a topic",
    tools=[DuckDuckGoTools()],
    add_datetime_to_context=True,
)

article_reader = Agent(
    name="Article Reader",
    role="Reads articles from URLs.",
    tools=[Newspaper4kTools()],
)

hn_team = Team(
    name="HackerNews Team",
    model=OpenAIChat(id="gpt-4o"),
    members=[hn_researcher, web_searcher, article_reader],
    instructions=[
        "First, search hackernews for what the user is asking about.",
        "Then, ask the article reader to read the links for the stories to get more information.",
        "Important: you must provide the article reader with the links to read.",
        "Then, ask the web searcher to search for each story to get more information.",
        "Finally, provide a thoughtful and engaging summary.",
    ],
    output_schema=Article,
    markdown=True,
    show_members_responses=True,
)

hn_team.print_response("Write an article about the top 2 stories on hackernews")
```

## 期望结果

团队将搜索HackerNews故事、阅读完整文章并搜索额外上下文。每个代理贡献其专业能力：发现故事、提取文章内容和网络搜索。

输出是一个结构化的Article对象，包含标题、综合摘要和参考链接。您将查看来自所有团队成员的响应，展示他们如何协作收集和综合信息。
