---
title: 讨论团队
---


此示例展示如何创建一个协作团队，允许多个代理使用`collaborate`模式共同研究主题。在协作模式下，所有团队成员都获得相同的任务，团队负责人将他们的输出综合成一个连贯的响应。

## 代码

```python cookbook/02_examples/teams/collaborate_mode/collaboration_team.py
import asyncio
from pathlib import Path
from textwrap import dedent

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.team import Team
from agno.tools.arxiv import ArxivTools
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.hackernews import HackerNewsTools

arxiv_download_dir = Path(__file__).parent.joinpath("tmp", "arxiv_pdfs__{session_id}")
arxiv_download_dir.mkdir(parents=True, exist_ok=True)

reddit_researcher = Agent(
    name="Reddit研究员",
    role="在Reddit上研究主题",
    model=OpenAIChat(id="gpt-5-mini"),
    tools=[DuckDuckGoTools()],
    add_name_to_context=True,
    instructions=dedent("""
    您是Reddit研究员。
    您将获得一个在Reddit上研究的主题。
    您需要找到Reddit上最相关的帖子。
    """),
)

hackernews_researcher = Agent(
    name="HackerNews研究员",
    model=OpenAIChat("gpt-5-mini"),
    role="在HackerNews上研究主题",
    tools=[HackerNewsTools()],
    add_name_to_context=True,
    instructions=dedent("""
    您是HackerNews研究员。
    您将获得一个在HackerNews上研究的主题。
    您需要找到HackerNews上最相关的帖子。
    """),
)

academic_paper_researcher = Agent(
    name="学术论文研究员",
    model=OpenAIChat("gpt-5-mini"),
    role="研究学术论文和学术内容",
    tools=[DuckDuckGoTools(), ArxivTools(download_dir=arxiv_download_dir)],
    add_name_to_context=True,
    instructions=dedent("""
    您是学术论文研究员。
    您将获得一个在学术文献中研究的主题。
    您需要找到相关的学术文章、论文和学术讨论。
    重点关注同行评审的内容和来自可靠来源的引用。
    提供关键发现和方法论的简要摘要。
    """),
)

twitter_researcher = Agent(
    name="Twitter研究员",
    model=OpenAIChat("gpt-5-mini"),
    role="研究热门讨论和实时更新",
    tools=[DuckDuckGoTools()],
    add_name_to_context=True,
    instructions=dedent("""
    您是Twitter/X研究员。
    您将获得一个在Twitter/X上研究的主题。
    您需要找到热门讨论、有影响力的声音和实时更新。
    尽可能关注经过验证的账户和可靠来源。
    跟踪相关话题标签和正在进行的对话。
    """),
)


agent_team = Team(
    name="讨论团队",
    delegate_to_all_members=True,
    model=OpenAIChat("gpt-5-mini"),
    members=[
        reddit_researcher,
        hackernews_researcher,
        academic_paper_researcher,
        twitter_researcher,
    ],
    instructions=[
        "您是讨论主持人。",
        "当您认为团队已达成共识时，必须停止讨论。",
    ],
    markdown=True,
    show_members_responses=True,
)

if __name__ == "__main__":
    asyncio.run(
        agent_team.aprint_response(
            input="Start the discussion on the topic: 'What is the best way to learn to code?'",
            stream=True,
        )
    )

```
