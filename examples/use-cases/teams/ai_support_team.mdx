构建一个智能客户支持团队，将查询路由到专门的代理，用于文档搜索、问题升级和反馈收集。此示例演示了使用知识库和外部集成的高级路由。

## 您将学习的内容

通过构建此团队，您将理解：
- 如何创建一个分类和引导客户查询的路由系统
- 如何将知识库与向量搜索集成以提供文档帮助
- 如何连接外部工具（如Slack）进行升级和反馈工作流
- 如何结合多个具有不同职责的专门代理

## 使用案例

构建客户支持平台、帮助台系统、技术文档助手或自动工单系统。

## 工作原理

团队使用智能路由将查询引导至专门的代理：

1. **分类**: 团队负责人分析查询类型（问题、错误、反馈）
2. **路由**: 根据分类将查询导向适当的代理
3. **处理**: 专门代理使用其工具处理查询
4. **集成**: 连接到外部系统（Slack、知识库）
5. **响应**: 向用户提供专业回复

每个代理都有其职责领域特定的工具和说明。

## 代码

```python ai_support_team.py
from agno.agent import Agent
from agno.knowledge.knowledge import Knowledge
from agno.knowledge.reader.website_reader import WebsiteReader
from agno.models.openai import OpenAIChat
from agno.team import Team
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.exa import ExaTools
from agno.tools.slack import SlackTools
from agno.vectordb.pgvector import PgVector

knowledge = Knowledge(
    vector_db=PgVector(
        table_name="website_documents",
        db_url="postgresql+psycopg://ai:ai@localhost:5532/ai",
    ),
)

knowledge.add_content(
    url="https://docs.agno.com/introduction",
    reader=WebsiteReader(
        # 从种子URL跟踪的链接数量
        max_links=10,
    ),
)
support_channel = "testing"
feedback_channel = "testing"

doc_researcher_agent = Agent(
    name="文档研究代理",
    role="搜索知识库以获取信息",
    model=OpenAIChat(id="gpt-4o"),
    tools=[DuckDuckGoTools(), ExaTools()],
    knowledge=knowledge,
    search_knowledge=True,
    instructions=[
        "您是给定产品文档专家。彻底搜索知识库以回答用户问题。",
        "始终根据文档提供准确信息。",
        "如果问题与常见问题匹配，请提供文档中的特定常见问题答案。",
        "在相关时，包含直接链接到解决用户问题的特定文档页面。",
        "如果您对某个答案不确定，请承认并建议用户在哪里能找到更多信息。",
        "在适当时，用标题、要点和代码示例清晰地格式化您的回复。",
        "始终验证您的答案是否直接解决了用户的特定问题。",
        "如果您无法在文档知识库中找到答案，请使用DuckDuckGoTools或ExaTools搜索网络相关信息以回答用户问题。",
    ],
)


escalation_manager_agent = Agent(
    name="升级管理代理",
    role="将问题升级到slack频道",
    model=OpenAIChat(id="gpt-4o"),
    tools=[SlackTools()],
    instructions=[
        "您是负责将关键问题路由到支持团队的升级经理。",
        f"当用户报告问题时，始终使用send_message工具包函数将问题连同所有相关详细信息发送到#{support_channel} Slack频道。",
        "包含用户姓名、联系信息（如可用）以及问题的清晰描述。",
        "升级问题后，回复用户确认其问题已被升级。",
        "您的回复应该专业且令人安心，让他们知道支持团队会很快处理它。",
        "如果可用，请始终包含工单或参考编号以帮助用户跟踪其问题。",
        "切勿试图自己解决技术问题 - 您的角色严格是升级和沟通。",
    ],
)

feedback_collector_agent = Agent(
    name="反馈收集代理",
    role="从用户处收集反馈",
    model=OpenAIChat(id="gpt-4o"),
    tools=[SlackTools()],
    description="您是能够从用户处收集反馈的AI代理。",
    instructions=[
        "您负责收集有关产品或功能请求的用户反馈。",
        f"当用户提供反馈或建议功能时，使用Slack工具通过send_message工具包函数将其发送到#{feedback_channel}频道。",
        "在您的Slack消息中包含用户反馈的所有相关信息。",
        "将反馈发送到Slack后，以专业方式回复用户并感谢他们的输入。",
        "您的回复应该承认他们的反馈并保证会予以考虑。",
        "在语气中保持温暖和感激，因为用户反馈对我们改进产品很有价值。",
        "不要承诺具体时间表或保证会实施他们的建议。",
    ],
)


customer_support_team = Team(
    name="客户支持团队",
    model=OpenAIChat(id="gpt-4o"),
    members=[doc_researcher_agent, escalation_manager_agent, feedback_collector_agent],
    markdown=True,
    debug_mode=True,
    show_members_responses=True,
    determine_input_for_members=False,
    respond_directly=True,
    instructions=[
        "您是负责分类和路由客户查询的首席客户支持代理。",
        "仔细分析每个用户消息并确定它是：需要文档研究的问题、需要升级的错误报告或产品反馈。",
        "对于有关产品的一般问题，路由到doc_researcher_agent，该代理将搜索文档以获取答案。",
        "如果doc_researcher_agent无法找到问题的答案，将其升级到escalation_manager_agent。",
        "对于错误报告或技术问题，立即路由到escalation_manager_agent。",
        "对于功能请求或产品反馈，路由到feedback_collector_agent。",
        "始终提供清晰的解释，说明为什么将查询路由到特定代理。",
        "从适当代理收到响应后，以专业和有益的方式将信息传达回用户。",
        "在整个对话中保持上下文，确保为用户提供无缝体验。",
    ],
)

# 添加查询，代理将其重定向到适当的代理
customer_support_team.print_response(
    "Hi Team, I want to build an educational platform where the models are have access to tons of study materials, How can Agno platform help me build this?",
    stream=True,
)
```

## 期望结果

团队将分析您的查询并将其路由到最合适的代理。文档问题通过搜索知识库获得解答，错误问题升级到Slack，反馈被收集和记录。

您将查看团队的分类决策和处理您请求的特定代理的回复。知识库集成能够在实际文档中实现准确答案，而Slack集成提供无缝的升级工作流。
