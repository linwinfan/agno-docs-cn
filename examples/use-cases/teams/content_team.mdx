Build a content creation 团队 with specialized re搜索ers and writers that collaborate to produce high-quality articles. 此示例演示 团队 coordination where 代理s work together on complex tasks.

## What You'll 学习

By building this 团队, you'll 理解:
- How 创建 specialized 代理s with distinct roles and capabilities
- How 团队s coordinate multiple 代理s using the coordinate mode
- How to combine web 搜索 工具s with writing expertise for content creation
- How to structure 团队 说明 for collaborative 工作流s

## 使用 Cases

Build content creation platforms, automated journalism systems, re搜索 report generators, or marketing content pipelines.

## How It Works

The 团队 uses coordinate mode 管理 collaboration between specialized 代理s:

1. **Re搜索**: Re搜索er 代理 搜索es the web using DuckDuckGo for relevant 信息
2. **Coordinate**: Team leader coordinates task distribution between 成员
3. **Write**: Writer 代理 crafts clear, engaging content based on re搜索 findings
4. **Integrate**: Team combines re搜索 and writing into cohesive articles

The 团队 leader manages the 工作流 and ensures both 代理s contribute their expertise.

## 代码

```python content_team.py
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.team import Team
from agno.tools.duckduckgo import DuckDuckGoTools

# Create individual specialized agents
researcher = Agent(
    name="Researcher",
    role="Expert at finding information",
    tools=[DuckDuckGoTools()],
    model=OpenAIChat(id="gpt-4o"),
)

writer = Agent(
    name="Writer",
    role="Expert at writing clear, engaging content",
    model=OpenAIChat(id="gpt-4o"),
)

# Create a team with these agents
content_team = Team(
    name="Content Team",
    members=[researcher, writer],
    instructions="You are a team of researchers and writers that work together to create high-quality content.",
    model=OpenAIChat(id="gpt-4o"),
    show_members_responses=True,
)

# Run the team with a task
content_team.print_response("Create a short article about quantum computing")
```

## What to Expect

The 团队 will create an article by first re搜索ing the topic through web 搜索, then writing content based on the findings. The re搜索er finds relevant 信息 and sources, while the writer transforms this into engaging prose.

The output 展示 responses from both 团队 成员 so you can 查看 how they collaborate. The final article combines accurate re搜索 with clear, professional writing.
