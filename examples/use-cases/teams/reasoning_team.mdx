Build a reasoning 团队 that handles complex queries by combining web 搜索, financial data, and transparent analytical thinking. 此示例演示 how reasoning 工具s make the 团队's decision-making process visible.

## What You'll 学习

By building this 团队, you'll 理解:
- How to integrate reasoning 工具s for transparent analytical thinking
- How to combine multiple specialized 代理s with different data sources
- How 使用 domain-specific 搜索 with Exa for financial 信息
- How to stream reasoning events to 查看 the 团队's thought process in real-time

## 使用 Cases

Build financial re搜索 platforms, investment analysis 工具s, market intelligence systems, or decision support 应用程序s.

## How It Works

The 团队 coordinates specialized 代理s with transparent reasoning:

1. **Analyze**: Team leader uses reasoning 工具s to plan the approach
2. **Search**: Web 代理 finds general 信息 using DuckDuckGo
3. **Re搜索**: Finance 代理 retrieves financial data from trusted sources
4. **Synthesize**: Team combines findings with visible reasoning process
5. **Present**: Outputs structured data with supporting logic

Reasoning 工具s provide transparency into how the 团队 thinks through complex queries.

## 代码

```python reasoning_team.py
from agno.agent import Agent
from agno.models.anthropic import Claude
from agno.models.openai import OpenAIChat
from agno.team import Team
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.reasoning import ReasoningTools
from agno.tools.exa import ExaTools

web_agent = Agent(
    name="Web Search Agent",
    role="Handle web search requests",
    model=OpenAIChat(id="gpt-4o"),
    tools=[DuckDuckGoTools()],
    instructions=["Always include sources"],
)

finance_agent = Agent(
    name="Finance Agent",
    role="Handle financial data requests",
    model=OpenAIChat(id="gpt-4o"),
    tools=[
        ExaTools(
            include_domains=["cnbc.com", "reuters.com", "bloomberg.com", "wsj.com"],
            show_results=True,
            text=False,
            highlights=False,
        )
    ],
    instructions=["Use tables to display data"],
)

team_leader = Team(
    name="Reasoning Team Leader",
    model=Claude(id="claude-3-7-sonnet-latest"),
    members=[
        web_agent,
        finance_agent,
    ],
    tools=[ReasoningTools(add_instructions=True)],
    markdown=True,
    show_members_responses=True,
)

team_leader.print_response(
    "Tell me 1 company in New York, 1 in San Francisco and 1 in Chicago and the stock price of each",
    stream=True,
    show_full_reasoning=True,
)
```

## What to Expect

The 团队 will re搜索 companies and stock prices by coordinating between web 搜索 and financial data 代理s. You'll 查看 the reasoning process as the 团队 plans its approach, delegates tasks, and synthesizes 信息.

The output includes visible thinking through reasoning 工具s, showing how the 团队 decides which 代理 使用 and how to combine their findings. Financial data is presented in tables with sources from trusted financial news outlets.
