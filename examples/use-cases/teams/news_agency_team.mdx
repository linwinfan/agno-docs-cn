---
title: 新闻机构团队
---


此示例展示如何创建一个新闻机构团队，该团队可以搜索网络、撰写文章并进行编辑。

## 代码

```python news_agency_team.py

from pathlib import Path

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.team import Team
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.newspaper4k import Newspaper4kTools

urls_file = Path(__file__).parent.joinpath("tmp", "urls__{session_id}.md")
urls_file.parent.mkdir(parents=True, exist_ok=True)


searcher = Agent(
    name="搜索员",
    role="搜索主题的顶级URL",
    instructions=[
        "给定一个主题，首先生成3个与该主题相关的搜索词列表。",
        "对每个搜索词，搜索网络并分析结果。返回与该主题最相关的10个URL。",
        "您为《纽约时报》撰稿，因此来源的质量很重要。",
    ],
    tools=[DuckDuckGoTools()],
    add_datetime_to_context=True,
)
writer = Agent(
    name="撰稿人",
    role="撰写高质量文章",
    description=(
        "您是《纽约时报》的资深撰稿人。给定一个主题和URL列表，"
        "您的目标是撰写一篇符合《纽约时报》水准的高质量文章。"
    ),
    instructions=[
        "首先使用`read_article`阅读所有URL。"
        "然后撰写一篇符合《纽约时报》水准的高质量文章。"
        "文章应结构良好、信息丰富、引人入胜且吸引人。",
        "确保文章长度至少与《纽约时报》封面故事相当——至少15段。",
        "确保提供细致入微且平衡的观点，在可能的情况下引用事实。",
        "注重清晰度、连贯性和整体质量。",
        "切勿编造事实或抄袭。始终提供适当的引用。",
        "记住：您为《纽约时报》撰稿，因此文章质量很重要。",
    ],
    tools=[Newspaper4kTools()],
    add_datetime_to_context=True,
)

editor = Team(
    name="编辑",
    model=OpenAIChat("gpt-5-mini"),
    members=[searcher, writer],
    description="您是《纽约时报》的资深编辑。给定一个主题，您的目标是撰写一篇符合《纽约时报》水准的文章。",
    instructions=[
        "首先要求搜索记者为该主题搜索最相关的URL。",
        "然后要求撰稿人获取一篇引人入胜的文章草稿。",
        "编辑、校对和润色文章，确保其符合《纽约时报》的高标准。",
        "文章应该极其清晰且文笔优美。"
        "注重清晰度、连贯性和整体质量。",
        "记住：您是文章发布前的最后一道把关人，因此请确保文章完美无缺。",
    ],
    add_datetime_to_context=True,
    markdown=True,
    debug_mode=True,
    show_members_responses=True,
)
editor.print_response("Write an article about latest developments in AI.")
```
