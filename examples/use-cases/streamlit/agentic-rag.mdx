---
title: 智能体 RAG
---


此示例应用程序展示如何构建一个复杂的 RAG（检索增强生成）系统，该系统利用知识库搜索与 LLM 结合，为数据提供深入洞察。

## 智能体可以：
- 处理和理解来自多个来源的文档（PDF、网站、文本文件）
- 使用向量嵌入构建可搜索的知识库
- 在会话之间维护对话上下文和记忆
- 为响应提供相关引用和来源
- 生成摘要并提取关键洞察
- 回答后续问题和澄清

## 智能体使用：
- 向量相似性搜索以检索相关文档
- 对话记忆以提供上下文响应
- 引用跟踪以进行来源归属
- 动态知识库更新

## 可尝试的示例查询：
- "这个文档的关键点是什么？"
- "可以总结一下主要论点和支持证据吗？"
- "有哪些重要的统计数据和发现？"
- "这与[主题X]有什么关系？"
- "这个分析存在哪些局限性或空白？"
- "你能更详细地解释[概念X]吗？"
- "还有哪些其他来源支持或反驳这些主张？"

## 代码

完整代码可在 [Agno 仓库](https://github.com/agno-agi/agno) 中获得。

## 用法

<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/agno-agi/agno.git
    cd agno
    ```
  </Step>

  <Step title="创建虚拟环境">
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```
  </Step>

  <Step title="安装依赖">
    ```bash
    pip install -r cookbook/02_examples/streamlit_apps/agentic_rag/requirements.txt
    ```
  </Step>

  <Step title="运行PgVector">
    首先，安装 [Docker Desktop](https://docs.docker.com/desktop/install/mac-install/)。

    然后使用辅助脚本运行：
    ```bash
    ./cookbook/scripts/run_pgvector.sh
    ```

    或直接使用Docker：
    ```bash
    docker run -d \
      -e POSTGRES_DB=ai \
      -e POSTGRES_USER=ai \
      -e POSTGRES_PASSWORD=ai \
      -e PGDATA=/var/lib/postgresql/data/pgdata \
      -v pgvolume:/var/lib/postgresql/data \
      -p 5532:5432 \
      --name pgvector \
      agnohq/pgvector:16
    ```
  </Step>


  <Step title="设置API密钥">
    ```bash
    # 必需
    export OPENAI_API_KEY=***
    # 可选
    export ANTHROPIC_API_KEY=***
    export GOOGLE_API_KEY=***

    ```
    我们建议使用 gpt-5-mini 以获得最佳性能。
  </Step>

  <Step title="启动应用程序">
    ```bash
    streamlit run cookbook/02_examples/streamlit_apps/agentic_rag/app.py
    ```
    打开 localhost:8501 开始使用智能体RAG。
  </Step>
</Steps>
