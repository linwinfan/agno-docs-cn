title: 井字棋对战
---


井字棋对战是一个井字棋游戏，多个 AI 智能体相互竞争，展示了多智能体系统在复杂游戏环境中的强大能力。

### 关键功能
- 多智能体系统：包含 X 和 O 棋子智能体用于选择移动
- 移动验证：专门的棋盘智能体确保遵守游戏规则
- 游戏协调：主智能体监督游戏流程和结束条件
- 交互式界面：使用 Streamlit 构建实时游戏可视化

### 系统组件
- X 棋子智能体：为 X 棋子制定策略并选择移动
- O 棋子智能体：控制并确定 O 棋子的移动
- 棋盘智能体：验证所有提议的移动是否符合游戏规则
- 主智能体：协调游戏流程并监控游戏状态

### 高级特性
该系统演示了复杂的智能体交互，其中每个 AI 组件都有特定的角色。智能体们相互通信和协调，创建完整的井字棋体验，展示了多个专业 AI 如何有效协同工作。

### 用法
<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/agno-agi/agno.git
    cd agno
    ```
  </Step>

  <Step title="创建虚拟环境">
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # Windows 使用：.venv\Scripts\activate
    ```
  </Step>

  <Step title="安装依赖">
    ```bash
    pip install -r cookbook/02_examples/streamlit_apps/tic_tac_toe/requirements.txt
    ```
  </Step>

  <Step title="设置 API 密钥">
    井字棋对战支持多种 AI 模型：

    ```bash
    # OpenAI 模型必需（GPT-4, GPT-3.5）
    export OPENAI_API_KEY=your_api_key_here

    # 可选 - 用于额外模型
    export ANTHROPIC_API_KEY=your_api_key_here  # Claude 模型
    export GOOGLE_API_KEY=your_api_key_here     # Gemini 模型
    export GROQ_API_KEY=your_api_key_here       # Groq 模型
    ```
  </Step>

  <Step title="启动应用">
    ```bash
    streamlit run cookbook/02_examples/streamlit_apps/tic_tac_toe/app.py
    ```
  </Step>

  <Step title="打开应用">
    然后，在浏览器中打开 http://localhost:8501 开始观看 AI 智能体玩井字棋。
  </Step>
</Steps>
