此示例展示 how 构建 Sage, a Perplexity-like Answer Engine that intelligently determines whether to perform a web 搜索 or conduct a deep analysis using ExaTools based on the user's query.

Sage:
1. 使用s real-time web 搜索 (DuckDuckGo) and deep contextual analysis (ExaTools) to provide comprehensive answers
2. Intelligently selects 工具s based on query complexity
3. Provides an interactive Streamlit UI with 会话 management and chat history 导出
4. Supports multiple LLM providers (OpenAI, Anthropic, Google, Groq)

## 密钥 capabilities
- Natural language query 理解ing and processing
- Real-time web 搜索 integration with DuckDuckGo
- Deep contextual analysis using ExaTools
- Multiple LLM provider support
- Session management using SQLite
- Chat history 导出
- Interactive Streamlit UI

## 用法

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/agno-agi/agno.git
    cd agno
    ```
  </Step>

  <Step title="Create virtual environment">
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # On Windows: .venv\Scripts\activate
    ```
  </Step>

  <Step title="Install dependencies">
    ```bash
    pip install -r cookbook/02_examples/streamlit_apps/answer_engine/requirements.txt
    ```
  </Step>

  <Step title="Set up API keys">
    ```bash
    # Required
    export OPENAI_API_KEY=***
    export EXA_API_KEY=***

    # Optional (for additional models)
    export ANTHROPIC_API_KEY=***
    export GOOGLE_API_KEY=***
    export GROQ_API_KEY=***
    ```
    We recommend using gpt-5-mini for optimal performance.
  </Step>

  <Step title="Launch the app">
    ```bash
    streamlit run cookbook/02_examples/streamlit_apps/answer_engine/app.py
    ```
    Open localhost:8501 to start using Sage.
  </Step>
</Steps>

## Model Selection
The 应用程序 supports multiple 模型 providers:
- OpenAI (o3-mini, gpt-5-mini)
- Anthropic (claude-3-5-sonnet)
- Google (gemini-2.0-flash-exp)
- Groq (llama-3.3-70b-versatile)

## Agent Configuration
The 代理 配置 is in `agents.py` and the prompts are in `prompts.py`:
- To modify prompts, update the `prompts.py` 文件
- To add new 工具s or 模型s, update the `agents.py` 文件
