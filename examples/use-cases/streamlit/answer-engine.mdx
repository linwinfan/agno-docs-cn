---


此示例展示如何构建 Sage，一个类似 Perplexity 的答案引擎，它能够根据用户查询智能地决定是否执行网络搜索或使用 ExaTools 进行深度分析。

Sage 的功能：
1. 使用实时网络搜索（DuckDuckGo）和深度上下文分析（ExaTools）提供全面的答案
2. 根据查询复杂度智能选择工具
3. 提供带有会话管理和聊天历史导出功能的交互式 Streamlit UI
4. 支持多个 LLM 提供商（OpenAI、Anthropic、Google、Groq）

## 核心功能
- 自然语言查询理解和处理
- 与 DuckDuckGo 集成的实时网络搜索
- 使用 ExaTools 进行深度上下文分析
- 多个 LLM 提供商支持
- 使用 SQLite 的会话管理
- 聊天历史导出
- 交互式 Streamlit UI

## 简单查询示例
- "告诉我关于美国在2025年实施的关税信息"
- "哪个是更好的推理模型：o3-mini 还是 DeepSeek R1？"
- "告诉我关于 Agno 的信息"
- "可再生能源的最新趋势是什么？"

## 高级分析查询示例
- "评估新兴AI法规如何影响创新"
- "比较电动车与氢能源车的环境影响"
- "分析全球半导体供应链面临的挑战"

## 用法

<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/agno-agi/agno.git
    cd agno
    ```
  </Step>

  <Step title="创建虚拟环境">
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # Windows: .venv\Scripts\activate
    ```
  </Step>

  <Step title="安装依赖">
    ```bash
    pip install -r cookbook/02_examples/streamlit_apps/answer_engine/requirements.txt
    ```
  </Step>

  <Step title="设置 API 密钥">
    ```bash
    # 必需
    export OPENAI_API_KEY=***
    export EXA_API_KEY=***

    # 可选（用于额外模型）
    export ANTHROPIC_API_KEY=***
    export GOOGLE_API_KEY=***
    export GROQ_API_KEY=***
    ```
    我们推荐使用 gpt-5-mini 以获得最佳性能。
  </Step>

  <Step title="启动应用">
    ```bash
    streamlit run cookbook/02_examples/streamlit_apps/answer_engine/app.py
    ```
    打开 localhost:8501 开始使用 Sage。
  </Step>
</Steps>

## 模型选择
该应用程序支持多个模型提供商：
- OpenAI (o3-mini, gpt-5-mini)
- Anthropic (claude-3-5-sonnet)
- Google (gemini-2.0-flash-exp)
- Groq (llama-3.3-70b-versatile)

## 智能体配置
智能体配置在 `agents.py` 文件中，提示词在 `prompts.py` 文件中：
- 要修改提示词，请更新 `prompts.py` 文件
- 要添加新工具或模型，请更新 `agents.py` 文件
