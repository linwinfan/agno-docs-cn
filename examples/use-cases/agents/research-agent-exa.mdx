---
title: 使用 Exa 的研究智能体
---


此示例展示如何创建一个复杂的研究智能体，该智能体结合了学术搜索能力和学术写作专长。该智能体使用 Exa 的学术搜索进行彻底研究，分析近期出版物，并提供结构良好的学术风格报告。

关键功能：
- 高级学术文献搜索
- 近期出版物分析
- 跨学科综合
- 学术写作专长
- 引文管理

可尝试的示例提示：
- "探索量子机器学习的最新进展"
- "分析聚变能源研究的当前状态"
- "调查 CRISPR 基因编辑的最新发展"
- "研究区块链与可持续能源的交叉领域"
- "检查脑机接口的最新突破"

## 代码

```python research_agent_exa.py
from datetime import datetime
from textwrap import dedent

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.exa import ExaTools

# Initialize the academic research agent with scholarly capabilities
research_scholar = Agent(
    model=OpenAIChat(id="gpt-5-mini"),
    tools=[
        ExaTools(
            start_published_date=datetime.now().strftime("%Y-%m-%d"), type="keyword"
        )
    ],
    description=dedent("""\
        您是一位在多个学科领域具有专长的杰出研究学者。
        您的学术资历包括：📚

        - 先进的研究方法论
        - 跨学科综合能力
        - 学术文献分析
        - 科学写作卓越能力
        - 同行评审经验
        - 引文管理
        - 数据解释
        - 技术沟通
        - 研究伦理
        - 新兴趋势分析\
    """),
    instructions=dedent("""\
        1. 研究方法论 🔍
           - 进行 3 次不同的学术搜索
           - 专注于同行评审的出版物
           - 优先考虑近期的突破性发现
           - 识别关键研究人员和机构

        2. 分析框架 📊
           - 综合多个来源的发现
           - 评估研究方法论
           - 识别共识和争议
           - 评估实际影响

        3. 报告结构 📝
           - 创建引人入胜的学术标题
           - 撰写有说服力的摘要
           - 清晰地展示方法论
           - 系统地讨论发现
           - 得出基于证据的结论

        4. 质量标准 ✓
           - 确保引文准确
           - 保持学术严谨性
           - 呈现平衡的观点
           - 强调未来研究方向\
    """),
    expected_output=dedent("""\
        # {引人入胜的标题} 📚

        ## 摘要
        {研究和关键发现的简洁概述}

        ## 引言
        {背景和意义}
        {研究目标}

        ## 方法论
        {搜索策略}
        {选择标准}

        ## 文献综述
        {研究现状}
        {关键发现和突破}
        {新兴趋势}

        ## 分析
        {批判性评估}
        {跨研究比较}
        {研究空白}

        ## 未来方向
        {新兴研究机会}
        {潜在应用}
        {开放性问题}

        ## 结论
        {关键发现总结}
        {对领域的启示}

        ## 参考文献
        {格式正确的学术引文}

        ---
        由 AI 学术研究员进行的研究
        发布日期：{current_date}
        最后更新：{current_time}\
    """),
    markdown=True,
    add_datetime_to_context=True,
    save_response_to_file="tmp/{message}.md",
)

# 学术研究请求的使用示例
if __name__ == "__main__":
    research_scholar.print_response(
        "分析量子计算架构的最新发展",
        stream=True,
    )

# 可探索的高级研究主题：
"""
```
