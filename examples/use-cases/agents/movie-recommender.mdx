---
title: 电影推荐器
---


此示例展示如何创建一个智能电影推荐系统，根据您的偏好提供全面的电影建议。该智能体结合电影数据库、评分、评论和即将发布的作品，提供个性化的电影推荐。

可尝试的示例提示：
- "推荐类似《盗梦空间》和《禁闭岛》的惊悚电影"
- "过去 2 年评分最高的喜剧电影是什么？"
- "为我找类似《寄生虫》和《老男孩》的韩国电影"
- "推荐评分良好的家庭友好冒险电影"
- "未来 6 个月即将上映的超级英雄电影有哪些？"

## 代码

```python movie_recommender.py
from textwrap import dedent

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.exa import ExaTools

movie_recommendation_agent = Agent(
    name="PopcornPal",
    tools=[ExaTools()],
    model=OpenAIChat(id="gpt-5-mini"),
    description=dedent("""\
        您是 PopcornPal，一位充满热情且知识渊博的电影策展人，在全球电影领域拥有专业知识！🎥

        您的使命是通过提供详细的、个性化的推荐来帮助用户发现他们下一部最喜欢的电影，
        这些建议基于用户的偏好、观影历史和最新的电影资讯。您将深厚的电影知识与当前的评分和评论相结合，
        推荐真正能引起每位观众共鸣的电影。"""),
    instructions=dedent("""\
        请按照以下步骤进行每次推荐：
        1. 分析阶段
           - 从用户输入中理解其偏好
           - 考虑提到的喜欢电影的主题和风格
           - 考虑任何特定要求（类型、评分、语言）

        2. 搜索与策划
           - 使用 Exa 搜索相关电影
           - 确保推荐的多样性
           - 验证所有电影数据都是最新且准确的

        3. 详细信息
           - 电影标题和发行年份
           - 类型和子类型
           - IMDB 评分（重点关注 7.5 分以上的电影）
           - 片长和主要语言
           - 简洁、引人入胜的剧情摘要
           - 内容建议/年龄分级
           - 著名演员和导演

        4. 额外功能
           - 在可用时包含相关预告片
           - 建议类似类型的即将上映作品
           - 在已知时提及流媒体可用性

        展示风格：
        - 使用清晰的 markdown 格式
        - 在结构化表格中展示主要推荐
        - 将相似的电影分组
        - 为类型添加表情符号指示器（🎭 🎬 🎪）
        - 每次查询至少提供 5 个推荐
        - 为每个推荐包含简要说明
    """),
    markdown=True,
    add_datetime_to_context=True,
    )

# Example usage with different types of movie queries
movie_recommendation_agent.print_response(
    "推荐一些 IMDB 评分 8 分以上的惊悚电影。"
    "我之前最喜欢的惊悚电影有《黑暗骑士》、《毒液》、《寄生虫》和《禁闭岛》。",
    stream=True,
)
```
