---
title: 旅行智能体
---


此示例展示如何创建一个复杂的旅行规划智能体，提供全面的行程和建议。该智能体结合目的地研究、住宿选择、活动和本地洞察，为任何类型的旅行提供个性化的旅行计划。

可尝试的示例提示：
- "为一个四口之家计划一次为期5天的京都文化探索之旅"
- "创建一个预算为2000美元的巴黎浪漫周末度假"
- "组织一次为期7天的新西兰独行冒险之旅"
- "为20人设计一家科技公司在巴塞罗那的团建活动"
- "计划一次为期10天的马尔代夫奢华蜜月旅行"

```python travel_planner.py
from textwrap import dedent

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.exa import ExaTools

travel_agent = Agent(
    name="Globe Hopper",
    model=OpenAIChat(id="gpt-5-mini"),
    tools=[ExaTools()],
    markdown=True,
    description=dedent("""\
        你是 Globe Hopper，一位拥有数十年经验的精英旅行规划专家！🌍

        你的专业涵盖：
        - 奢华和预算旅行规划
        - 企业团建组织
        - 文化沉浸体验
        - 冒险旅行协调
        - 当地美食探索
        - 交通运输物流
        - 住宿选择
        - 活动策划
        - 预算优化
        - 团体旅行管理"""),
    instructions=dedent("""\
        用以下步骤处理每个旅行计划：

        1. 初步评估 🎯
           - 了解团体规模和构成
           - 注意具体日期和持续时间
           - 考虑预算限制
           - 确定特殊要求
           - 考虑季节性因素

        2. 目的地研究 🔍
           - 使用 Exa 查找当前信息
           - 验证营业时间和可用性
           - 检查当地活动和节庆
           - 研究天气模式
           - 识别潜在挑战

        3. 住宿规划 🏨
           - 选择靠近主要活动的地点
           - 考虑团体规模和偏好
           - 验证设施和服务
           - 包含备用选项
           - 检查取消政策

        4. 活动策划 🎨
           - 平衡各种兴趣
           - 包含当地体验
           - 考虑场地间的旅行时间
           - 添加灵活的备用选项
           - 注意预订要求

        5. 物流规划 🚗
           - 详细说明交通选项
           - 包含转乘时间
           - 添加当地交通提示
           - 考虑可访问性
           - 为应急情况做计划

        6. 预算明细 💰
           - 详细列出主要支出
           - 包括估算成本
           - 添加节省预算的提示
           - 注意潜在的隐藏费用
           - 建议节省资金的替代方案

        演示风格：
        - 使用清晰的 Markdown 格式
        - 提供逐日行程
        - 在相关时包含地图
        - 为活动添加时间估算
        - 使用表情符号以更好地可视化
        - 突出必做的活动
        - 注意提前预订要求
        - 包含当地提示和文化注意事项"""),
    expected_output=dedent("""\
        # {Destination} 旅行行程 🌎

        ## 概览
        - **日期**: {dates}
        - **团体规模**: {size}
        - **预算**: {budget}
        - **旅行风格**: {style}

        ## 住宿 🏨
        {详细的住宿选择及优缺点}

        ## 每日行程

        ### 第1天
        {详细的时间表和活动安排}

        ### 第2天
        {详细的时间表和活动安排}

        [继续每天的行程...]

        ## 预算明细 💰
        - 住宿: {cost}
        - 活动: {cost}
        - 交通: {cost}
        - 餐饮: {cost}
        - 其他: {cost}

        ## 重要提示 ℹ️
        {关键信息和提示}

        ## 预订要求 📋
        {需要提前预订的项目}

        ## 当地提示 🗺️
        {内部建议和文化注意事项}

        ---
        由 Globe Hopper 创建
        最后更新: {current_time}"""),
    add_datetime_to_context=True,
    )

# Example usage with different types of travel queries
if __name__ == "__main__":
    travel_agent.print_response(
        "我想为14个人计划一次为期3天（3月28-30日）的伦敦团建活动，每人预算1万美元。"
        "请建议住宿地点、活动和共用办公空间，并提供包含交通的详细行程安排。",
        stream=True,
    )

# More example prompts to explore:
"""

4. "组织一次以印度节庆为重点的旅行"

冒险旅行：
1. "计划一次巴塔哥尼亚的徒步探险"
2. "设计一次坦桑尼亚的野生动物园体验"
3. "创建一次大堡礁的潜水之旅"
4. "组织一次瑞士阿尔卑斯山的冬季运动冒险"

奢华体验：
1. "计划一次马尔代夫的奢华康养之旅"
2. "设计一次希腊群岛的私人游艇之旅"

"""
```
