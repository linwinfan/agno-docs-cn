---
title: 购物助手
---

购物助手是一个由 AI 驱动的产品推荐系统，帮助用户根据其特定偏好和需求找到完美的产品。该智能体专注于：

- **智能产品匹配**：分析用户偏好并找到最符合其标准的产品，确保最低 50% 的匹配率
- **可信来源**：仅搜索亚马逊、Flipkart、Myntra、Meesho、Google 购物、耐克等真实电商平台和其他知名网站
- **实时可用性**：验证推荐产品有库存且可供购买
- **质量保证**：避免假冒或未经验证的产品，确保用户安全
- **详细信息**：提供包括价格、品牌、功能和关键属性在内的全面产品信息
- **用户友好格式**：以清晰、有条理的方式呈现推荐，便于用户理解

该智能体特别适用于：
- 在预算限制内寻找特定产品
- 当首选商品不可用时发现替代品
- 基于多个标准获得个性化推荐
- 确保从可信、合法的来源购买
- 节省产品搜索和比较的时间

## 代码

```python cookbook/02_examples/agents/shopping_partner.py
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.exa import ExaTools

agent = Agent(
    name="shopping partner",
    model=OpenAIChat(id="gpt-5-mini"),
    instructions=[
        "您是一个产品推荐智能体，专门寻找符合用户偏好的产品。",
        "优先寻找尽可能满足用户要求的产品，但确保最低 50% 的匹配率。",
        "仅从亚马逊、Flipkart、Myntra、Meesho、Google 购物、耐克等真实可信的电商平台和其他知名平台搜索产品。",
        "验证每个产品推荐都有库存且可供购买。",
        "避免推荐假冒或未经验证的产品。",
        "在回复中清楚地提及每个产品的关键属性（例如价格、品牌、功能）。",
        "以整洁的格式呈现推荐，并确保清晰易懂。",
    ],
    tools=[ExaTools()],
)
agent.print_response(
    "我正在寻找跑鞋，偏好如下：颜色：黑色 用途：适合长距离跑步 预算：低于 10,000 卢比"
)

```
