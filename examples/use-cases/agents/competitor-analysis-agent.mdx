构建一个 AI 智能体，通过结合网络搜索、内容抓取和推理工具执行全面的竞争情报分析，分析竞争对手并生成具有可操作洞察的战略报告。

## 您将学到什么

通过构建这个智能体，您将了解：
- 如何集成多个工具（Firecrawl 和 ReasoningTools）来实现复杂工作流
- 如何通过清晰的指令构建多阶段研究流程
- 推理工具如何使智能体的分析思维透明化
- 如何定义结构化输出模板以确保报告的一致性

## 使用场景

构建市场研究工具、竞争情报系统、战略规划助手或投资决策的尽职调查平台。

## 工作原理

智能体遵循系统化的五阶段研究流程：

1. **发现**：使用网络搜索查找竞争对手和行业信息
2. **分析**：抓取网站并提取详细信息
3. **比较**：分析功能和竞争定位
4. **综合**：使用推理工具进行 SWOT 分析
5. **报告**：将发现汇编成可操作的建议

在整个过程中，推理工具提供智能体分析思维的透明度。

## 代码

```python competitor_analysis_agent.py
from textwrap import dedent

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.firecrawl import FirecrawlTools
from agno.tools.reasoning import ReasoningTools

competitor_analysis_agent = Agent(
    model=OpenAIChat(id="gpt-4.1"),
    tools=[
        FirecrawlTools(
            enable_search=True,
            enable_crawl=True,
            enable_mapping=True,
            formats=["markdown", "links", "html"],
            search_params={
                "limit": 2,
            },
            limit=5,
        ),
        ReasoningTools(
            add_instructions=True,
        ),
    ],
    instructions=[
        "1. 初步研究与发现:",
        "   - 使用搜索工具查找目标公司的信息",
        "   - 搜索'[公司名称] 竞争对手', '像 [公司名称] 一样的公司'",
        "   - 搜索行业报告和市场分析",
        "   - 使用 think 工具规划您的研究方法",
        "2. 竞争对手识别:",
        "   - 使用 Firecrawl 搜索每个已识别的竞争对手",
        "   - 查找他们的官方网站和关键信息来源",
        "   - 绘制竞争格局图",
        "3. 网站分析:",
        "   - 使用 Firecrawl 抓取竞争对手网站",
        "   - 映射他们的网站结构以了解他们的产品",
        "   - 提取产品信息、定价和价值主张",
        "   - 查找案例研究和客户评价",
        "4. 深度竞争分析:",
        "   - 在收集每个竞争对手的信息后使用分析工具",
        "   - 比较功能、定价和市场定位",
        "   - 识别模式和竞争动态",
        "   - 思考您发现的含义",
        "5. 战略综合:",
        "   - 对每个主要竞争对手进行 SWOT 分析",
        "   - 使用推理来识别竞争优势",
        "   - 分析市场趋势和机会",
        "   - 制定战略建议",
        "- 在开始主要研究阶段之前始终使用 think 工具",
        "- 使用分析工具处理发现并提取见解",
        "- 搜索每个竞争对手的多个视角",
        "- 通过检查多个来源验证信息",
        "- 在分析中要彻底但专注",
        "- 提供基于证据的建议",
    ],
    expected_output=dedent("""\
    # Competitive Analysis Report: {Target Company}

    ## Executive Summary
    {High-level overview of competitive landscape and key findings}

    ## Research Methodology
    - Search queries used
    - Websites analyzed
    - Key information sources

    ## Market Overview
    ### Industry Context
    - Market size and growth rate
    - Key trends and drivers
    - Regulatory environment

    ### Competitive Landscape
    - Major players identified
    - Market segmentation
    - Competitive dynamics

    ## Competitor Analysis

    ### Competitor 1: {Name}
    #### Company Overview
    - Website: {URL}
    - Founded: {Year}
    - Headquarters: {Location}
    - Company size: {Employees/Revenue if available}

    #### Products & Services
    - Core offerings
    - Key features and capabilities
    - Pricing model and tiers
    - Target market segments

    #### Digital Presence Analysis
    - Website structure and user experience
    - Key messaging and value propositions
    - Content strategy and resources
    - Customer proof points

    #### SWOT Analysis
    **Strengths:**
    - {Evidence-based strengths}

    **Weaknesses:**
    - {Identified weaknesses}

    **Opportunities:**
    - {Market opportunities}

    **Threats:**
    - {Competitive threats}

    ### Competitor 2: {Name}
    {Similar structure as above}

    ### Competitor 3: {Name}
    {Similar structure as above}

    ## Comparative Analysis

    ### Feature Comparison Matrix
    | Feature | {Target} | Competitor 1 | Competitor 2 | Competitor 3 |
    |---------|----------|--------------|--------------|--------------|
    | {Feature 1} | ✓/✗ | ✓/✗ | ✓/✗ | ✓/✗ |
    | {Feature 2} | ✓/✗ | ✓/✗ | ✓/✗ | ✓/✗ |

    ### Pricing Comparison
    | Company | Entry Level | Professional | Enterprise |
    |---------|-------------|--------------|------------|
    | {Pricing details extracted from websites} |

    ### Market Positioning Analysis
    {Analysis of how each competitor positions themselves}

    ## Strategic Insights

    ### Key Findings
    1. {Major insight with evidence}
    2. {Competitive dynamics observed}
    3. {Market gaps identified}

    ### Competitive Advantages
    - {Target company's advantages}
    - {Unique differentiators}

    ### Competitive Risks
    - {Main threats from competitors}
    - {Market challenges}

    ## Strategic Recommendations

    ### Immediate Actions (0-3 months)
    1. {Quick competitive responses}
    2. {Low-hanging fruit opportunities}

    ### Short-term Strategy (3-12 months)
    1. {Product/service enhancements}
    2. {Market positioning adjustments}

    ### Long-term Strategy (12+ months)
    1. {Sustainable differentiation}
    2. {Market expansion opportunities}

    ## Conclusion
    {Summary of competitive position and strategic imperatives}
    """),
    markdown=True,
    add_datetime_to_context=True,
    stream_events=True,
)

competitor_analysis_agent.print_response(
    """分析支付行业中 Stripe 的竞争格局。
    重点关注他们的产品、定价模型和市场定位。""",
    stream=True,
    show_full_reasoning=True,
)
```

## 预期效果

智能体将在五个阶段进行全面的竞争分析。它使用 Firecrawl 搜索竞争对手并抓取他们的网站，然后应用推理工具分析发现。分析以实时流式传输，因此您可以跟随智能体的研究和思考过程。

最终输出是一个详细的战略报告，包含竞争对手档案、SWOT 分析、比较表和按时间线（立即、短期、长期）组织的可操作建议。
