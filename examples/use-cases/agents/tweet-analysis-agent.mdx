title: 推文分析智能体
description: 一个分析推文并提供全面品牌监控和情感分析的智能体。
---


关键功能：
- 实时推文分析和情感分类
- 参与度指标分析（点赞、转发、回复）
- 品牌健康监控和竞争情报
- 战略建议和响应策略

## 代码
```python social_media_agent.py
from textwrap import dedent

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.x import XTools

social_media_agent = Agent(
    name="Social Media Analyst",
    model=OpenAIChat(id="gpt-5-mini"),
    tools=[
        XTools(
            include_post_metrics=True,
            wait_on_rate_limit=True,
        )
    ],
    instructions=dedent("""\
        你是一位资深的品牌情报分析师，专门从事 X（Twitter）上的社交媒体监听。
        你的任务：将原始推文内容和参与度指标转化为高管级别的智能报告。

        核心分析步骤：
        1. 数据收集
           - 使用 X 工具检索推文
           - 分析文本内容和参与度指标
           - 重点关注点赞、转发、回复和覆盖范围

        2. 情感分类
           - 对每条推文进行分类：正面/负面/中性/混合
           - 识别原因（功能赞扬、错误投诉等）
           - 根据参与度数量和作者影响力加权

        3. 模式检测
           - 病毒式推广（高点赞和转发，低回复）
           - 争议信号（低点赞，高回复）
           - 意见领袖影响和认证账户活动

        4. 主题分析
           - 提取重复出现的关键词和主题
           - 识别功能反馈和痛点
           - 跟踪竞争对手提及和比较
           - 发现新兴使用案例

        报告格式：
        - 包含品牌健康评分（1-10）的执行摘要
        - 包含代表性引述的关键主题
        - 风险分析和机会识别
        - 战略建议（即时/短期/长期）
        - 高影响力帖子的响应策略

        指导原则：
        - 保持客观和基于证据
        - 专注于可操作的见解
        - 突出需要关注的紧急问题
        - 提供解决方案导向的建议"""),
    markdown=True,
    )

social_media_agent.print_response(
    "分析 X（Twitter）上 Agno 和 AgnoAGI 最近 10 条推文的情感"
)
```

<Note> 查看详细的 [Social Media Agent](https://github.com/agno-agi/agno/tree/main/cookbook/02_examples/agents/social_media_agent.py). </Note>
