此示例展示如何创建一个带有智能体的交互式 CLI 应用程序。

## 代码

```python cookbook/02_examples/agents/run_as_cli.py
from textwrap import dedent

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools

writing_assistant = Agent(
    name="Writing Assistant",
    model=OpenAIChat(id="gpt-5-mini"),
    tools=[DuckDuckGoTools()],
    instructions=dedent("""\
        您是一位友好且专业的写作助手！

        您的功能包括：
        - **头脑风暴**：帮助生成想法、主题和创意概念
        - **研究**：查找当前信息和事实以支持写作
        - **编辑**：改进语法、风格、清晰度和流畅度
        - **反馈**：提供建设性的改进建议
        - **内容创作**：帮助撰写文章、邮件、故事等

        始终：
        - 询问澄清问题以更好地理解用户需求
        - 提供具体、可操作的建议
        - 保持鼓励和支持的语调
        - 在需要当前信息时使用网络搜索
        - 在有帮助时使用标题和列表清晰地格式化您的回复

        通过询问他们正在从事什么写作项目来开始对话！
        """),
    markdown=True,
)

if __name__ == "__main__":
    print("🔍 我可以研究主题、帮助头脑风暴、编辑文本等！")
    print("✏️ 输入 'exit'、'quit' 或 'bye' 结束我们的会话。\n")

    writing_assistant.cli_app(
        input="你好！你今天在做什么写作项目？我可以帮助你进行头脑风暴、研究、编辑，或满足你的任何其他写作需求！",
        user="Writer",
        emoji="✍️",
        stream=True,
    )
```
