`RetryAgentRun`异常允许您向模型提供关于如何更改其行为的指令，并让模型在当前智能体运行中重试。异常消息作为工具调用错误传递给模型，使模型能够在LLM循环的下一次迭代中调整其方法。

<Note>
这**不会**重试整个智能体运行——它只在当前运行的工具调用循环内向模型提供反馈。
</Note>

## 构造函数

```python
RetryAgentRun(
    exc: str,
    user_message: Optional[Union[str, Message]] = None,
    agent_message: Optional[Union[str, Message]] = None,
    messages: Optional[List[Union[dict, Message]]] = None,
)
```

### 参数

<ResponseField name="exc" type="str" required>
  要传递给模型的错误消息。此消息提供指令或反馈，帮助模型在下一次迭代中调整其行为。
</ResponseField>

<ResponseField name="user_message" type="Union[str, Message]" optional>
  可选的消息，向用户显示有关重试的信息。
</ResponseField>

<ResponseField name="agent_message" type="Union[str, Message]" optional>
  可选的消息，从智能体的角度显示有关重试的信息。
</ResponseField>

<ResponseField name="messages" type="List[Union[dict, Message]]" optional>
  可选的消息列表，添加到对话历史中。
</ResponseField>


## 使用场景

在以下情况下使用`RetryAgentRun`：

- **验证失败**：输入不符合要求，您希望模型使用修正后的输入重试
- **状态要求**：当前状态不满足先决条件，您希望模型执行额外的操作
- **业务逻辑**：条件未满足，您希望指导模型如何继续
- **迭代优化**：您希望模型根据反馈改进其方法

## 行为

当抛出`RetryAgentRun`时：

1. 异常消息作为错误添加到工具调用结果中
2. 模型在下一次LLM调用中接收此错误
3. 模型可以调整其方法并重试工具调用或尝试不同的方法
4. 智能体运行继续（不会停止或退出）
5. 所有消息和工具调用都保留在会话中
