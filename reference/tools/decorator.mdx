---

| 参数 | 类型 | 描述 |
|------|------|------|
| `name` | `str` | 函数名称的覆盖值 |
| `description` | `str` | 函数描述的覆盖值 |
| `stop_after_tool_call` | `bool` | 如果为True，智能体将在函数调用后停止 |
| `tool_hooks` | `list[Callable]` | 包装函数执行的钩子列表 |
| `pre_hook` | `Callable` | 在函数执行前运行的钩子 |
| `post_hook` | `Callable` | 在函数执行后运行的钩子 |
| `requires_confirmation` | `bool` | 如果为True，执行前需要用户确认 |
| `requires_user_input` | `bool` | 如果为True，执行前需要用户输入 |
| `user_input_fields` | `list[str]` | 需要用户输入的字段列表 |
| `external_execution` | `bool` | 如果为True，工具将在智能体控制之外执行 |
| `cache_results` | `bool` | 如果为True，启用函数结果缓存 |
| `cache_dir` | `str` | 存储缓存文件的目录 |
| `cache_ttl` | `int` | 缓存结果的生存时间（秒）（默认：3600） |
