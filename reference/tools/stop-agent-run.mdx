`StopAgentRun`异常允许您退出模型执行循环并结束智能体运行。当从工具函数中抛出时，智能体会立即退出工具调用循环，并将运行状态设置为`COMPLETED`。到该点为止的所有会话状态、消息、工具调用和工具结果都会存储在数据库中。

<Note>
这**不会**取消智能体运行。它在退出工具调用循环后优雅地完成运行。
</Note>

## 构造函数

```python
StopAgentRun(
    exc: str,
    user_message: Optional[Union[str, Message]] = None,
    agent_message: Optional[Union[str, Message]] = None,
    messages: Optional[List[Union[dict, Message]]] = None,
)
```

### 参数

<ResponseField name="exc" type="str" required>
  停止执行的原因。此消息会被记录，可用于调试或用户反馈。
</ResponseField>

<ResponseField name="user_message" type="Union[str, Message]" optional>
  可选的消息，向用户显示为什么执行停止。
</ResponseField>

<ResponseField name="agent_message" type="Union[str, Message]" optional>
  可选的消息，从智能体的角度显示停止信息。
</ResponseField>

<ResponseField name="messages" type="List[Union[dict, Message]]" optional>
  可选的消息列表，在停止前添加到对话历史中。
</ResponseField>

## 使用场景

在以下情况下使用`StopAgentRun`：

- **严重错误**：发生无法恢复的错误
- **安全触发**：违反安全阈值或策略
- **任务完成**：任务已完全完成，不需要进一步的工具调用
- **资源限制**：达到资源限制（时间、成本、API调用次数）
- **需要人工干预**：情况需要人工审查或批准
- **提前终止**：您希望基于业务逻辑退出工具调用循环

## 行为

当抛出`StopAgentRun`时：

1. 工具调用循环立即退出
2. 不再执行进一步的工具调用
3. 运行状态设置为`COMPLETED`
4. 所有会话状态保存到数据库
5. 到该点为止的所有消息和工具调用都被保留
6. 可选的`user_message`或`agent_message`可以显示给用户
