`Toolkit`类提供了一种将多个工具（函数）分组和管理在一起的方法。它处理工具注册、过滤、缓存和执行控制。

## 导入

```python
from agno.tools.toolkit import Toolkit
```

## 构造函数

### 参数

| 参数 | 类型 | 描述 |
|------|------|------|
| `name` | `str` | 工具包的描述性名称。 |
| `tools` | `List[Callable]` | 要包含在工具包中的可调用函数列表。 |
| `instructions` | `str` | 使用工具包的说明。可以添加到智能体上下文中。 |
| `add_instructions` | `bool` | 是否将工具包说明添加到智能体的上下文中。 |
| `include_tools` | `list[str]` | 要从工具包中包含的工具名称列表。如果指定，只有这些工具会被注册。 |
| `exclude_tools` | `list[str]` | 要从工具包中排除的工具名称列表。这些工具不会被注册。 |
| `requires_confirmation_tools` | `list[str]` | 执行前需要用户确认的工具名称列表。 |
| `external_execution_required_tools` | `list[str]` | 将在智能体循环之外执行的工具名称列表。 |
| `stop_after_tool_call_tools` | `List[str]` | 执行后应停止智能体的工具名称列表。 |
| `show_result_tools` | `List[str]` | 结果应显示给用户的工具名称列表。 |
| `cache_results` | `bool` | 启用函数结果的内存缓存。 |
| `cache_ttl` | `int` | 缓存结果的生存时间（秒）（默认：1小时）。 |
| `cache_dir` | `str` | 存储缓存文件的目录。默认为系统临时目录。 |
| `auto_register` | `bool` | 是否在初始化时自动注册工具包中的所有工具。 |

## 使用示例

### 基本工具包

```python
from agno.tools.toolkit import Toolkit

class WebSearchTools(Toolkit):
    def __init__(self, **kwargs):
        tools = [
            self.search_web,
        ]
        super().__init__(name="web_search_tools", tools=tools, **kwargs)

    def search_web(self, query: str) -> str:
        """搜索网络信息。"""
        return f"正在搜索: {query}"
```

### 带说明的工具包

```python
class CalculatorTools(Toolkit):
    def __init__(self, **kwargs):
        tools = [
            self.add,
            self.subtract,
            self.multiply,
            self.divide,
        ]

        instructions = "使用这些工具执行计算。执行前始终验证输入。"

        super().__init__(name="calculator_tools", tools=tools, instructions=instructions, **kwargs)

    def add(self, a: float, b: float) -> float:
        """将两个数字相加并返回结果。"""
        return a + b

    def subtract(self, a: float, b: float) -> float:
        """将两个数字相减并返回结果。"""
        return a - b

    def multiply(self, a: float, b: float) -> float:
        """将两个数字相乘并返回结果。"""
        return a * b

    def divide(self, a: float, b: float) -> float:
        """将两个数字相除并返回结果。"""
        return a / b
```
