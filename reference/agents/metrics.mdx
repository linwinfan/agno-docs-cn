## 属性

| 字段 | 描述 |
|------|------|
| input_tokens | 模型提示/输入中的令牌数量。 |
| output_tokens | 模型生成的输出令牌数量。 |
| total_tokens | 使用的总令牌数（输入 + 输出）。 |
| audio_input_tokens | 输入中的音频令牌。 |
| audio_output_tokens | 输出中的音频令牌。 |
| audio_total_tokens | 总音频令牌数（如果使用音频输入/输出）。 |
| cache_read_tokens | 从缓存提供的令牌数（如果使用缓存）。 |
| cache_write_tokens | 写入缓存的令牌数。 |
| reasoning_tokens | 用于推理步骤的令牌数（如果启用）。 |
| time_to_first_token | 生成第一个令牌的时间（秒）。 |
| duration | 总运行时间（秒）。 |
| provider_metrics | 提供商特定的指标（字典）。 |
| additional_metrics | 模型/工具提供的任何额外指标（例如，延迟、成本等）。 |

> 注意：并非所有字段始终存在；这取决于模型/工具和运行情况。
