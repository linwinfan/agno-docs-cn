`RemoteAgent`允许您运行托管在远程AgentOS实例上的智能体。它提供与本地智能体相同的接口，使集成远程智能体到您的应用程序或将它们组合成团队和工作流变得容易。

## 安装

```bash
pip install agno
```

## 基本用法

```python
from agno.agent import RemoteAgent

# 创建指向远程AgentOS实例的远程智能体
agent = RemoteAgent(
    base_url="http://localhost:7777",
    agent_id="my-agent",
)

# 运行智能体（异步）
response = await agent.arun("法国的首都是什么？")
print(response.content)
```

## 参数

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `base_url` | `str` | 必需 | 远程AgentOS实例的基础URL（例如，`"http://localhost:7777"`） |
| `agent_id` | `str` | 必需 | 要执行的远程智能体ID |
| `timeout` | `float` | `60.0` | 请求超时时间（秒） |
| `config_ttl` | `float` | `300.0` | 缓存配置的生存时间（秒） |

## 属性

### `id`

返回智能体ID。

```python
print(agent.id)  # "my-agent"
```

### `name`

从远程配置返回智能体名称。

```python
print(agent.name)  # "My Agent"
```

### `description`

从远程配置返回智能体描述。

```python
print(agent.description)  # "A helpful assistant agent"
```

### `role`

从远程配置返回智能体角色。

```python
print(agent.role)  # "assistant"
```

### `tools`

以字典列表形式返回智能体工具。

```python
tools = agent.tools
if tools:
    for tool in tools:
        print(tool["name"])
```

### `db`

如果智能体配置了数据库，则返回`RemoteDb`实例。

```python
if agent.db:
    print(f"数据库ID: {agent.db.id}")
```

### `knowledge`

如果智能体配置了知识库，则返回`RemoteKnowledge`实例。

```python
if agent.knowledge:
    print("智能体已启用知识库")
```

## 方法

### `arun`

异步执行远程智能体。

```python
# 非流式
response = await agent.arun(
    "告诉我关于Python的信息",
    user_id="user-123",
    session_id="session-456",
)
print(response.content)

# 流式
async for event in agent.arun(
    "给我讲个故事",
    stream=True,
    user_id="user-123",
):
    if hasattr(event, "content") and event.content:
        print(event.content, end="", flush=True)
```

**参数：**

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `input` | `str \| List \| Dict \| Message \| BaseModel` | 必需 | 智能体的输入消息 |
| `stream` | `bool` | `False` | 是否流式传输响应 |
| `user_id` | `Optional[str]` | `None` | 运行的用户ID |
| `session_id` | `Optional[str]` | `None` | 用于上下文持久性的会话ID |
| `session_state` | `Optional[Dict]` | `None` | 会话状态字典 |
| `images` | `Optional[Sequence[Image]]` | `None` | 要包含的图像 |
| `audio` | `Optional[Sequence[Audio]]` | `None` | 要包含的音频 |
| `videos` | `Optional[Sequence[Video]]` | `None` | 要包含的视频 |
| `files` | `Optional[Sequence[File]]` | `None` | 要包含的文件 |
| `stream_events` | `Optional[bool]` | `None` | 是否流式传输事件 |
| `retries` | `Optional[int]` | `None` | 重试次数 |
| `knowledge_filters` | `Optional[Dict]` | `None` | 知识搜索过滤器 |
| `add_history_to_context` | `Optional[bool]` | `None` | 将历史添加到上下文 |
| `dependencies` | `Optional[Dict]` | `None` | 依赖字典 |
| `metadata` | `Optional[Dict]` | `None` | 元数据字典 |
| `auth_token` | `Optional[str]` | `None` | 用于认证的JWT令牌 |

**返回：**
- 当`stream=False`时返回`RunOutput`
- 当`stream=True`时返回`AsyncIterator[RunOutputEvent]`

### `acontinue_run`

使用工具结果继续暂停的智能体运行。

```python
from agno.models.response import ToolExecution

response = await agent.acontinue_run(
    run_id="run-123",
    updated_tools=[
        ToolExecution(
            tool_call_id="call-1",
            result="Tool result here",
        )
    ],
)
```

**参数：**

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `run_id` | `str` | 必需 | 要继续的运行ID |
| `updated_tools` | `List[ToolExecution]` | 必需 | 工具执行结果 |
| `stream` | `bool` | `False` | 是否流式传输响应 |
| `user_id` | `Optional[str]` | `None` | 用户ID |
| `session_id` | `Optional[str]` | `None` | 会话ID |
| `auth_token` | `Optional[str]` | `None` | 用于认证的JWT令牌 |

**返回：**
- 当`stream=False`时返回`RunOutput`
- 当`stream=True`时返回`AsyncIterator[RunOutputEvent]`

### `cancel_run`

取消正在运行的智能体执行。

```python
success = await agent.cancel_run(run_id="run-123")
if success:
    print("运行已取消")
```

**参数：**

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `run_id` | `str` | 必需 | 要取消的运行ID |
| `auth_token` | `Optional[str]` | `None` | 用于认证的JWT令牌 |

**返回：** `bool` - 如果成功取消则为True

### `get_agent_config`

从远程服务器获取智能体配置（始终获取最新配置）。

```python
config = await agent.get_agent_config()
print(f"智能体名称: {config.name}")
print(f"模型: {config.model}")
```

**返回：** `AgentResponse`

### `refresh_config`

强制刷新缓存的智能体配置。

```python
config = agent.refresh_config()
```

**返回：** `AgentResponse`

## 在团队中使用

远程智能体可以用作本地团队的成员：

```python
from agno.agent import RemoteAgent
from agno.team import Team
from agno.models.openai import OpenAIChat

# 来自另一个AgentOS实例的远程智能体
researcher = RemoteAgent(
    base_url="http://research-server:7777",
    agent_id="researcher-agent",
)

# 带有远程智能体成员的本地团队
team = Team(
    name="研究团队",
    model=OpenAIChat(id="gpt-4o"),
    members=[researcher],
    instructions="协调研究任务",
)

response = await team.arun("研究AI趋势")
```

## 在AgentOS网关中使用

远程智能体可以在本地AgentOS中注册以创建网关：

```python
from agno.agent import RemoteAgent
from agno.os import AgentOS

agent_os = AgentOS(
    agents=[
        RemoteAgent(base_url="http://server-1:7777", agent_id="agent-1"),
        RemoteAgent(base_url="http://server-2:7777", agent_id="agent-2"),
    ],
)
```

更多详情请参见[AgentOS网关](/agent-os/remote-execution/gateway)。

## 错误处理

```python
from agno.exceptions import RemoteServerUnavailableError

try:
    response = await agent.arun("你好")
except RemoteServerUnavailableError as e:
    print(f"远程服务器不可用: {e.message}")
```

## 认证

对于需要认证的AgentOS实例，请传递`auth_token`参数：

```python
response = await agent.arun(
    "你好",
    auth_token="your-jwt-token",
)
```
