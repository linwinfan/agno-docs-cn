`@hook`装饰器允许您配置单个钩子的行为。它可以应用于预钩子和后钩子。

## 导入

```python
from agno.hooks import hook
```

## 参数

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `run_in_background` | `bool` | `False` | 当为`True`时，钩子在响应发送后作为后台任务运行。需要[AgentOS](/agent-os/overview)。 |

## 使用方法

### 后台执行

标记一个钩子在后台运行而不阻塞API响应：

```python
from agno.hooks import hook

@hook(run_in_background=True)
async def log_analytics(run_output, agent):
    """在响应发送给用户后运行。"""
    await store_metrics(run_output)
```

### 与常规钩子结合

您可以在同一个智能体上混合使用后台和常规钩子：

```python
from agno.hooks import hook

def validate_output(run_output, agent):
    """同步运行，在完成前阻塞响应。"""
    if not run_output.content:
        raise OutputCheckError("不允许空响应")

@hook(run_in_background=True)
async def send_notification(run_output, agent):
    """在响应发送后在后台运行。"""
    await notify_user(run_output.content)

agent = Agent(
    model=OpenAIChat(id="gpt-4o"),
    post_hooks=[validate_output, send_notification],
)
```

## 重要说明

<Warning>
**后台执行需要AgentOS。** 当直接运行智能体（不通过AgentOS）时，标记为`run_in_background=True`的钩子将同步执行。
</Warning>

<Warning>
**后台钩子不能修改数据。** 由于后台钩子在响应发送后运行，对`run_input`、`run_output`或其他参数的任何修改都不会影响智能体的处理。仅将后台模式用于日志记录、分析或通知。
</Warning>
