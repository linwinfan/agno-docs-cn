`CompressionManager`负责压缩工具调用结果，以节省上下文空间同时保留关键信息。

## 压缩管理器属性

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `model` | `Optional[Model]` | `None` | 用于压缩的模型 |
| `compress_tool_results` | `bool` | `True` | 启用工具结果压缩的标志 |
| `compress_tool_results_limit` | `Optional[int]` | `None` | 触发压缩前未压缩工具结果的数量。|
| `compress_token_limit` | `Optional[int]` | `None` | 触发压缩前的令牌数量。 |
| `compress_tool_call_instructions` | `Optional[str]` | `None` | 压缩的自定义提示。如果未提供，则使用默认压缩提示 |
| `stats` | `Dict[str, Any]` | `{}` | 跟踪压缩统计信息 |

## 压缩管理器方法

### `should_compress(messages, tools, model) -> bool`

根据配置的阈值检查是否应触发压缩。

**参数：**
- `messages`: 要检查的消息列表
- `tools`: 用于令牌计数的可选工具列表
- `model`: 智能体/团队模型

**返回：**
- `bool`: 如果任一阈值满足则为True

### `ashould_compress(messages, tools, model) -> bool`

异步根据配置的阈值检查是否应触发压缩。

**参数：**
- `messages`: 要检查的消息列表
- `tools`: 用于令牌计数的可选工具列表
- `model`: 智能体/团队模型

**返回：**
- `bool`: 如果任一阈值满足则为True

### `compress(messages: List[Message]) -> None`

压缩所有未压缩的工具结果。

**参数：**
- `messages`: 包含要压缩的工具结果的消息列表

**返回：**
- `None`: 就地修改消息，在每个工具消息上设置`compressed_content`

### `acompress(messages: List[Message]) -> None`

异步压缩所有未压缩的工具结果。

**参数：**
- `messages`: 包含要压缩的工具结果的消息列表

**返回：**
- `None`: 就地修改消息，在每个工具消息上设置`compressed_content`
