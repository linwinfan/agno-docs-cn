`AgentOSClient`提供了与运行中的AgentOS实例交互的便捷接口。它支持所有AgentOS操作，包括运行智能体、团队和工作流，管理会话和记忆，以及搜索知识库。

## 基本用法

```python
from agno.client import AgentOSClient

# 连接到AgentOS
client = AgentOSClient(base_url="http://localhost:7777")

# 获取配置
config = await client.aget_config()
print(f"连接到: {config.name or config.os_id}")
print(f"可用智能体: {[a.id for a in config.agents]}")
```

## 参数

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `base_url` | `str` | 必需 | AgentOS实例的基础URL（例如，`"http://localhost:7777"`） |
| `timeout` | `float` | `60.0` | 请求超时时间（秒） |

## 方法

### 发现和配置

#### `aget_config`

异步获取AgentOS配置和元数据。

```python
config = await client.aget_config()
```

**返回:** 包含以下内容的`ConfigResponse`：
- `os_id`: OS实例的唯一标识符
- `name`: OS实例的名称
- `agents`: 已注册智能体列表
- `teams`: 已注册团队列表
- `workflows`: 已注册工作流列表
- `interfaces`: 可用接口列表

#### `get_config`

`aget_config`的同步版本。

```python
config = client.get_config()
```

#### `list_agents`

列出AgentOS实例中配置的所有智能体。

```python
agents = await client.list_agents()
for agent in agents:
    print(f"{agent.id}: {agent.name}")
```

**返回:** `List[AgentSummaryResponse]`

#### `aget_agent`

获取特定智能体的详细配置。

```python
agent = await client.aget_agent(agent_id="my-agent")
print(f"名称: {agent.name}")
print(f"模型: {agent.model}")
print(f"工具: {agent.tools}")
```

**参数:**
- `agent_id` (str): 要检索的智能体ID

**返回:** `AgentResponse`

#### `list_teams`

列出AgentOS实例中配置的所有团队。

```python
teams = await client.list_teams()
```

**返回:** `List[TeamSummaryResponse]`

#### `aget_team`

获取特定团队的详细配置。

```python
team = await client.aget_team(team_id="my-team")
```

**参数:**
- `team_id` (str): 要检索的团队ID

**返回:** `TeamResponse`

#### `list_workflows`

列出AgentOS实例中配置的所有工作流。

```python
workflows = await client.list_workflows()
```

**返回:** `List[WorkflowSummaryResponse]`

#### `aget_workflow`

获取特定工作流的详细配置。

```python
workflow = await client.aget_workflow(workflow_id="my-workflow")
```

**参数:**
- `workflow_id` (str): 要检索的工作流ID

**返回:** `WorkflowResponse`

### 运行智能体

#### `run_agent`

执行智能体运行（非流式）。

```python
result = await client.run_agent(
    agent_id="my-agent",
    message="What is 2 + 2?",
    session_id="session-123",
    user_id="user-456",
)
print(f"响应: {result.content}")
print(f"Tokens: {result.metrics.total_tokens}")
```

**参数:**
| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `agent_id` | `str` | 必需 | 要运行的智能体ID |
| `message` | `str` | 必需 | 智能体的消息/提示 |
| `session_id` | `Optional[str]` | `None` | 用于上下文持久性的会话ID |
| `user_id` | `Optional[str]` | `None` | 运行的用户ID |
| `images` | `Optional[Sequence[Image]]` | `None` | 要包含的图像 |
| `audio` | `Optional[Sequence[Audio]]` | `None` | 要包含的音频 |
| `videos` | `Optional[Sequence[Video]]` | `None` | 要包含的视频 |
| `files` | `Optional[Sequence[File]]` | `None` | 要包含的文件 |
| `session_state` | `Optional[Dict]` | `None` | 会话状态字典 |
| `dependencies` | `Optional[Dict]` | `None` | 依赖字典 |
| `metadata` | `Optional[Dict]` | `None` | 元数据字典 |
| `knowledge_filters` | `Optional[Dict]` | `None` | 知识搜索过滤器 |

**返回:** `RunOutput`

#### `run_agent_stream`

流式传输智能体运行响应。

```python
from agno.run.agent import RunContentEvent, RunCompletedEvent

async for event in client.run_agent_stream(
    agent_id="my-agent",
    message="Tell me a story",
):
    if isinstance(event, RunContentEvent):
        print(event.content, end="", flush=True)
    elif isinstance(event, RunCompletedEvent):
        print(f"\n运行ID: {event.run_id}")
```

**参数:** 与`run_agent`相同

**产生:** `RunOutputEvent`（`RunStartedEvent`、`RunContentEvent`、`RunToolCallEvent`、`RunCompletedEvent`等之一）

#### `continue_agent_run`

使用工具结果继续暂停的智能体运行。

```python
from agno.models.response import ToolExecution

result = await client.continue_agent_run(
    agent_id="my-agent",
    run_id="run-123",
    tools=[
        ToolExecution(
            tool_call_id="call-1",
            result="Tool result here",
        )
    ],
)
```

**参数:**
| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `agent_id` | `str` | 必需 | 智能体ID |
| `run_id` | `str` | 必需 | 要继续的运行ID |
| `tools` | `List[ToolExecution]` | 必需 | 工具执行结果 |
| `session_id` | `Optional[str]` | `None` | 会话ID |
| `user_id` | `Optional[str]` | `None` | 用户ID |

**返回:** `RunOutput`

#### `cancel_agent_run`

取消智能体运行。

```python
await client.cancel_agent_run(agent_id="my-agent", run_id="run-123")
```

### 记忆操作

#### `create_memory`

创建新用户记忆。

```python
memory = await client.create_memory(
    memory="User prefers dark mode",
    user_id="user-123",
    topics=["preferences", "ui"],
)
print(f"已创建: {memory.memory_id}")
```

**参数:**
| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `memory` | `str` | 必需 | 要存储的记忆内容 |
| `user_id` | `str` | 必需 | 与记忆关联的用户ID |
| `topics` | `Optional[List[str]]` | `None` | 用于分类记忆的主题 |
| `db_id` | `Optional[str]` | `None` | 要使用的数据库ID |

**返回:** `UserMemorySchema`

#### `list_memories`

带过滤和分页的用户记忆列表。

```python
memories = await client.list_memories(
    user_id="user-123",
    topics=["preferences"],
    limit=10,
)
for mem in memories.data:
    print(f"{mem.memory_id}: {mem.memory}")
```

**参数:**
| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `user_id` | `Optional[str]` | `None` | 按用户ID过滤 |
| `topics` | `Optional[List[str]]` | `None` | 按主题过滤 |
| `search_content` | `Optional[str]` | `None` | 在记忆内容中搜索 |
| `limit` | `int` | `20` | 每页记忆数量 |
| `page` | `int` | `1` | 页码 |

**返回:** `PaginatedResponse[UserMemorySchema]`

#### `get_memory`

按ID获取特定记忆。

```python
memory = await client.get_memory(memory_id="mem-123", user_id="user-123")
```

**返回:** `UserMemorySchema`

#### `update_memory`

更新现有记忆。

```python
updated = await client.update_memory(
    memory_id="mem-123",
    memory="User strongly prefers dark mode",
    user_id="user-123",
    topics=["preferences", "ui", "accessibility"],
)
```

**返回:** `UserMemorySchema`

#### `delete_memory`

删除特定记忆。

```python
await client.delete_memory(memory_id="mem-123", user_id="user-123")
```

### 会话操作

#### `create_session`

创建新会话。

```python
from agno.db.base import SessionType

session = await client.create_session(
    session_type=SessionType.AGENT,
    agent_id="my-agent",
    user_id="user-123",
    session_name="My Chat Session",
)
print(f"会话ID: {session.session_id}")
```

**参数:**
| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `session_type` | `SessionType` | `SessionType.AGENT` | 会话类型（AGENT, TEAM, WORKFLOW） |
| `session_id` | `Optional[str]` | `None` | 可选会话ID（如未提供则自动生成） |
| `user_id` | `Optional[str]` | `None` | 与会话关联的用户ID |
| `session_name` | `Optional[str]` | `None` | 人类可读的会话名称 |
| `agent_id` | `Optional[str]` | `None` | 智能体ID（用于智能体会话） |
| `team_id` | `Optional[str]` | `None` | 团队ID（用于团队会话） |
| `workflow_id` | `Optional[str]` | `None` | 工作流ID（用于工作流会话） |

**返回:** `AgentSessionDetailSchema`、`TeamSessionDetailSchema`或`WorkflowSessionDetailSchema`

#### `get_sessions`

带过滤和分页的会话列表。

```python
sessions = await client.get_sessions(
    user_id="user-123",
    session_type=SessionType.AGENT,
    limit=20,
)
for session in sessions.data:
    print(f"{session.session_id}: {session.session_name}")
```

**返回:** `PaginatedResponse[SessionSchema]`

#### `get_session`

按ID获取特定会话。

```python
session = await client.get_session(
    session_id="session-123",
    session_type=SessionType.AGENT,
)
```

**返回:** `AgentSessionDetailSchema`、`TeamSessionDetailSchema`或`WorkflowSessionDetailSchema`

#### `get_session_runs`

获取特定会话的所有运行。

```python
runs = await client.get_session_runs(session_id="session-123")
for run in runs:
    print(f"{run.run_id}: {run.content[:50]}...")
```

**返回:** `List[RunSchema | TeamRunSchema | WorkflowRunSchema]`

#### `rename_session`

重命名会话。

```python
session = await client.rename_session(
    session_id="session-123",
    session_name="My Updated Session Name",
)
```

**返回:** 会话详细信息模式

#### `delete_session`

删除特定会话。

```python
await client.delete_session(session_id="session-123")
```

### 知识操作

#### `upload_knowledge_content`

上传内容到知识库。

```python
from agno.media import File

content = await client.upload_knowledge_content(
    name="My Document",
    description="Important documentation",
    file=File(content=b"...", filename="doc.pdf", mime_type="application/pdf"),
)
print(f"内容ID: {content.id}")
```

**参数:**
| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `name` | `Optional[str]` | `None` | 内容名称 |
| `description` | `Optional[str]` | `None` | 内容描述 |
| `url` | `Optional[str]` | `None` | 要获取内容的URL |
| `file` | `Optional[File]` | `None` | 要上传的文件对象 |
| `text_content` | `Optional[str]` | `None` | 原始文本内容 |
| `reader_id` | `Optional[str]` | `None` | 用于处理的读取器 |
| `chunker` | `Optional[str]` | `None` | 分块策略 |

**返回:** `ContentResponseSchema`

#### `search_knowledge`

搜索知识库。

```python
results = await client.search_knowledge(
    query="What is Agno?",
    limit=5,
)
for result in results.data:
    print(f"评分: {result.score}")
    print(f"内容: {result.content[:100]}...")
```

**参数:**
| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `query` | `str` | 必需 | 搜索查询字符串 |
| `max_results` | `Optional[int]` | `None` | 要返回的最大结果数 |
| `filters` | `Optional[Dict]` | `None` | 要应用的过滤器 |
| `search_type` | `Optional[str]` | `None` | 搜索类型（向量、关键词、混合） |

**返回:** `PaginatedResponse[VectorSearchResult]`

#### `list_knowledge_content`

列出知识库中的所有内容。

```python
content = await client.list_knowledge_content(limit=20)
for item in content.data:
    print(f"{item.id}: {item.name}")
```

**返回:** `PaginatedResponse[ContentResponseSchema]`

#### `get_knowledge_config`

获取知识库配置。

```python
config = await client.get_knowledge_config()
print(f"读取器: {config.readers}")

```

**返回:** `KnowledgeConfigResponse`

## 错误处理

当远程服务器不可用时，客户端会引发`RemoteServerUnavailableError`：

```python
from agno.exceptions import RemoteServerUnavailableError

try:
    config = await client.aget_config()
except RemoteServerUnavailableError as e:
    print(f"服务器不可用: {e.message}")
    print(f"基础URL: {e.base_url}")
```

对于HTTP错误（4xx, 5xx），客户端会引发`httpx.HTTPStatusError`。

## 认证

要在请求中包含认证头，请将`headers`参数传递给任何方法：

```python
headers = {"Authorization": "Bearer your-token"}
config = await client.aget_config(headers=headers)
```
