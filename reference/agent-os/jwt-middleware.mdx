用于AgentOS的JWT认证中间件，可选RBAC（基于角色的访问控制）。

## 导入

```python
from agno.os.middleware import JWTMiddleware
from agno.os.middleware.jwt import TokenSource
```

## JWTMiddleware参数

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `verification_keys` | `Optional[List[str]]` | `JWT_VERIFICATION_KEY`环境变量 | 用于JWT验证的密钥列表。对于RS256，使用公钥。对于HS256，使用共享密钥。按顺序尝试每个密钥直到成功 - 适用于接受来自多个颁发者的令牌。 |
| `jwks_file` | `Optional[str]` | `JWT_JWKS_FILE`环境变量 | 静态JWKS（JSON Web Key Set）文件路径。根据JWT头部中的`kid`（密钥ID）查找密钥。 |
| `secret_key` | `Optional[str]` | `None` | **(已弃用)** 请改用`verification_keys`。 |
| `algorithm` | `str` | `"RS256"` | JWT算法（RS256, HS256, ES256等） |
| `validate` | `bool` | `True` | 是否验证JWT令牌 |
| `authorization` | `Optional[bool]` | `None` | 启用RBAC范围检查 |
| `token_source` | `TokenSource` | `TokenSource.HEADER` | 从何处提取JWT令牌 |
| `token_header_key` | `str` | `"Authorization"` | 授权的头部键 |
| `cookie_name` | `str` | `"access_token"` | JWT令牌的Cookie名称 |
| `scopes_claim` | `str` | `"scopes"` | 范围的JWT声明名称 |
| `user_id_claim` | `str` | `"sub"` | 用户ID的JWT声明名称 |
| `session_id_claim` | `str` | `"session_id"` | 会话ID的JWT声明名称 |
| `audience_claim` | `str` | `"aud"` | 受众/OS ID的JWT声明名称 |
| `verify_audience` | `bool` | `False` | 验证`aud`声明是否匹配AgentOS ID |
| `dependencies_claims` | `Optional[List[str]]` | `None` | 为`dependencies`参数提取的声明 |
| `session_state_claims` | `Optional[List[str]]` | `None` | 为`session_state`参数提取的声明 |
| `scope_mappings` | `Optional[Dict[str, List[str]]]` | `None` | 自定义路由到范围的映射（添加到默认值） |
| `excluded_route_paths` | `Optional[List[str]]` | 见下文 | 跳过JWT/RBAC检查的路由 |
| `admin_scope` | `Optional[str]` | `"agent_os:admin"` | 授予完全管理员访问权限的范围 |

## TokenSource枚举

| 值 | 描述 |
|----|------|
| `TokenSource.HEADER` | 从`Authorization: Bearer <token>`头部提取JWT |
| `TokenSource.COOKIE` | 从HTTP Cookie提取JWT |
| `TokenSource.BOTH` | 先尝试头部，然后回退到Cookie |

## 默认排除的路由

```python
[
    "/",
    "/health",
    "/docs",
    "/redoc",
    "/openapi.json",
    "/docs/oauth2-redirect",
]
```

## 使用方法

### 基本JWT验证

```python
from agno.os import AgentOS
from agno.os.middleware import JWTMiddleware

agent_os = AgentOS(agents=[my_agent])
app = agent_os.get_app()

app.add_middleware(
    JWTMiddleware,
    verification_keys=["your-jwt-key"],
    algorithm="RS256",
    validate=True,
)
```

### 带RBAC授权的JWT

```python
app.add_middleware(
    JWTMiddleware,
    verification_keys=["your-jwt-key"],
    algorithm="RS256",
    authorization=True,
    verify_audience=True,
)
```

### 从Cookie获取JWT

```python
from agno.os.middleware.jwt import TokenSource

app.add_middleware(
    JWTMiddleware,
    verification_keys=["your-jwt-key"],
    token_source=TokenSource.COOKIE,
    cookie_name="access_token",
)
```

### 参数注入

```python
app.add_middleware(
    JWTMiddleware,
    verification_keys=["your-jwt-key"],
    user_id_claim="sub",
    session_id_claim="session_id",
    dependencies_claims=["name", "email", "roles"],
    session_state_claims=["preferences"],
)
```

### 使用JWKS文件

```python
# 使用静态JWKS文件（例如，来自您的身份提供商）
app.add_middleware(
    JWTMiddleware,
    jwks_file="/path/to/jwks.json",
    algorithm="RS256",
    authorization=True,
)
```

JWKS文件应具有标准格式：

```json
{
  "keys": [
    {
      "kty": "RSA",
      "kid": "my-key-id",
      "use": "sig",
      "alg": "RS256",
      "n": "0vx7agoebGc...",
      "e": "AQAB"
    }
  ]
}
```

### 自定义范围映射

```python
app.add_middleware(
    JWTMiddleware,
    verification_keys=["your-jwt-key"],
    authorization=True,
    scope_mappings={
        # 覆盖默认范围
        "GET /agents": ["custom:agents:list"],
        # 添加新端点
        "POST /custom/action": ["custom:write"],
        # 允许无需范围
        "GET /public": [],
    }
)
```

## 请求状态

处理后，中间件将以下内容存储在`request.state`中：

| 属性 | 类型 | 描述 |
|------|------|------|
| `authenticated` | `bool` | 用户是否已认证 |
| `user_id` | `Optional[str]` | 令牌声明中的用户ID |
| `session_id` | `Optional[str]` | 令牌声明中的会话ID |
| `scopes` | `List[str]` | 用户的权限范围 |
| `audience` | `Optional[str]` | 受众声明值 |
| `token` | `str` | 原始JWT令牌 |
| `authorization_enabled` | `bool` | 是否启用了RBAC |
| `dependencies` | `Dict[str, Any]` | 提取的依赖声明 |
| `session_state` | `Dict[str, Any]` | 提取的会话状态声明 |
| `accessible_resource_ids` | `Set[str]` | 用户可访问的资源ID（用于列表端点） |

## 错误响应

| 状态码 | 描述 |
|--------|------|
| `401 Unauthorized` | 缺少或无效的JWT令牌 |
| `401 Unauthorized` | 令牌已过期 |
| `401 Unauthorized` | 无效受众（令牌不是为此AgentOS准备的） |
| `403 Forbidden` | 请求操作的范围不足 |
