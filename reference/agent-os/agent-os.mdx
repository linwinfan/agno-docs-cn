## 参数

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `id` | `Optional[str]` | 自动生成的UUID | AgentOS ID |
| `name` | `Optional[str]` | `None` | AgentOS名称 |
| `description` | `Optional[str]` | `None` | AgentOS描述 |
| `version` | `Optional[str]` | `None` | AgentOS版本 |
| `agents` | `Optional[List[Agent]]` | `None` | AgentOS中可用的智能体列表 |
| `teams` | `Optional[List[Team]]` | `None` | AgentOS中可用的团队列表 |
| `workflows` | `Optional[List[Workflow]]` | `None` | AgentOS中可用的工作流列表 |
| `knowledge` | `Optional[List[Knowledge]]` | `None` | AgentOS中可用的独立知识实例列表 |
| `interfaces` | `Optional[List[BaseInterface]]` | `None` | AgentOS中可用的接口列表 |
| `a2a_interface` | `bool` | `False` | 是否在A2A服务器中暴露OS智能体和团队 |
| `authorization` | `bool` | `False` | 是否启用RBAC授权 |
| `authorization_config` | `Optional[AuthorizationConfig]` | `None` | 启用授权时的JWT验证配置 |
| `cors_allowed_origins` | `Optional[List[str]]` | `None` | 允许的CORS来源列表（与默认Agno域合并） |
| `config` | `Optional[Union[str, AgentOSConfig]]` | `None` | 用户提供的AgentOS配置。可以是YAML文件路径或`AgentOSConfig`实例。 |
| `settings` | `Optional[AgnoAPISettings]` | `None` | AgentOS API的设置 |
| `base_app` | `Optional[FastAPI]` | `None` | 用于AgentOS的自定义FastAPI APP |
| `lifespan` | `Optional[Any]` | `None` | FastAPI应用的生命周期上下文管理器 |
| `enable_mcp_server` | `bool` | `False` | 是否启用MCP（模型上下文协议） |
| `on_route_conflict` | `Literal["preserve_agentos", "preserve_base_app", "error"]` | `"preserve_agentos"` | 提供自定义base_app时检测到路由冲突时的操作。 |
| `tracing` | `bool` | `False` | 为所有智能体和团队启用OpenTelemetry追踪 |
| `tracing_db` | `Optional[Union[BaseDb, AsyncBaseDb]]` | `None` | 用于存储追踪的专用数据库 |
| `auto_provision_dbs` | `bool` | `True` | 是否自动配置数据库 |
| `run_hooks_in_background` | `bool` | `False` | 将智能体/团队的预/后钩子作为FastAPI后台任务运行 |
| `telemetry` | `bool` | `True` | 记录最小遥测数据用于分析 |

## 授权

通过设置`authorization=True`并设置`JWT_VERIFICATION_KEY`环境变量为JWT验证公钥来启用RBAC：

```python
from agno.os import AgentOS
from agno.os.config import AuthorizationConfig

agent_os = AgentOS(
    id="my-agent-os",
    agents=[my_agent],
    authorization=True,
)
```

或者为了更多控制，您可以使用`AuthorizationConfig`类：

```python
from agno.os import AgentOS
from agno.os.config import AuthorizationConfig

agent_os = AgentOS(
    id="my-agent-os",
    agents=[my_agent],
    authorization=True,
    authorization_config=AuthorizationConfig(
        verification_keys=["your-jwt-verification-key"],
        algorithm="RS256",
    ),
)
```

配置选项请参见[AuthorizationConfig](/reference/agent-os/authorization-config)。

## 函数

### `get_app`

获取为AgentOS配置的FastAPI APP。

### `get_routes`

获取为AgentOS配置的路由。

### `serve`

运行应用，有效地启动AgentOS。

**参数：**

- `app` (Union[str, FastAPI]): FastAPI APP实例
- `host` (str): 要绑定的主机。默认为`localhost`
- `port` (int): 要绑定的端口。默认为`7777`
- `workers` (Optional[int]): 要使用的工作者数量。默认为`None`
- `reload` (bool): 为开发启用自动重载。默认为`False`

### `resync`

重新同步AgentOS以发现、初始化和配置：智能体、团队、工作流、数据库和知识库。

**参数：**

- `app` (FastAPI): FastAPI应用实例
