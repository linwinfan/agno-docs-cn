在AgentOS上启用RBAC授权时的JWT验证配置。

## 导入

```python
from agno.os.config import AuthorizationConfig
```

## 参数

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `verification_keys` | `Optional[List[str]]` | `None` | 用于验证JWT签名的密钥列表。对于非对称算法（如RS256），使用公钥。对于对称算法（如HS256），使用共享密钥。按顺序尝试每个密钥直到成功 - 适用于接受来自多个颁发者的令牌。 |
| `jwks_file` | `Optional[str]` | `None` | 包含公钥的静态JWKS（JSON Web Key Set）文件路径。根据JWT头部中的`kid`（密钥ID）匹配密钥。作为RSA密钥管理的`verification_keys`替代方案。 |
| `algorithm` | `Optional[str]` | `RS256` | 用于令牌验证的JWT算法。常见选项：`RS256`（非对称），`HS256`（对称）。 |
| `verify_audience` | `Optional[bool]` | `False` | 是否验证JWT令牌的受众声明。对于AgentOS控制平面流量，不应启用此选项。 |

## 使用方法

```python
from agno.os import AgentOS
from agno.os.config import AuthorizationConfig

agent_os = AgentOS(
    id="my-agent-os",
    agents=[my_agent],
    authorization=True,
    authorization_config=AuthorizationConfig(
        verification_keys=["your-public-key-or-secret"],
        algorithm="RS256",
    ),
)
```

## 算法选项

| 算法 | 类型 | 密钥格式 |
|------|------|----------|
| `RS256` | 非对称（RSA） | 公钥（PEM格式） |
| `RS384` | 非对称（RSA） | 公钥（PEM格式） |
| `RS512` | 非对称（RSA） | 公钥（PEM格式） |
| `HS256` | 对称（HMAC） | 共享密钥字符串 |
| `HS384` | 对称（HMAC） | 共享密钥字符串 |
| `HS512` | 对称（HMAC） | 共享密钥字符串 |
| `ES256` | 非对称（ECDSA） | 公钥（PEM格式） |
| `ES384` | 非对称（ECDSA） | 公钥（PEM格式） |
| `ES512` | 非对称（ECDSA） | 公钥（PEM格式） |

## 示例

### 使用RS256（非对称）

```python
# 使用公钥的RS256
authorization_config = AuthorizationConfig(
    verification_keys=["""-----BEGIN PUBLIC KEY-----
MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...
-----END PUBLIC KEY-----"""],
    algorithm="RS256",
)
```

### 使用HS256（对称）

```python
# 使用共享密钥的HS256
authorization_config = AuthorizationConfig(
    verification_keys=["your-256-bit-secret-key"],
    algorithm="HS256",
)
```

### 使用JWKS文件

```python
# 使用JWKS文件的RS256
authorization_config = AuthorizationConfig(
    jwks_file="/path/to/jwks.json",
    algorithm="RS256",
)
```

JWKS文件应遵循标准格式：

```json
{
  "keys": [
    {
      "kty": "RSA",
      "kid": "my-key-id",
      "use": "sig",
      "alg": "RS256",
      "n": "0vx7agoebGc...",
      "e": "AQAB"
    }
  ]
}
```
