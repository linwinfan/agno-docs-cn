在您使用Agno构建的系统中，智能体会自主做出决策，与外部工具交互，并以仅从记录的会话中无法立即看到的方式相互协调。可观测性是掌握您的智能体正在做什么以及系统性能如何的关键。

**Agno 追踪** 是为您的Agno智能体、团队和工作流引入可观测性的推荐方式。
它会自动捕获所有相关的执行细节，帮助您了解智能体的行为，简化调试并帮助您优化系统。

追踪利用 [OpenTelemetry](https://opentelemetry.io/) 对Agno智能体和团队进行检测，捕获追踪和跨度。

## 为什么可观测性很重要？

随着您的Agno系统变得越来越复杂（智能体使用多个工具、做出顺序决策并与其它智能体协调），理解其行为变得具有挑战性。

**Agno 追踪** 解决了这个问题：

- **调试**: 当智能体失败时，准确查看出了什么问题
- **性能**: 识别智能体执行中的瓶颈
- **成本跟踪**: 监控token使用量和API调用
- **行为分析**: 理解决策模式
- **审计跟踪**: 跟踪智能体做了什么以及为什么这样做

<Note>
所有Agno追踪数据都存储在您自己的数据库中。追踪数据不会离开您的系统，也不会发送给第三方：您完全掌控。
</Note>

## 理解追踪和跨度

将追踪想象成智能体执行的家族树：

### 追踪 (Trace)
一个 **追踪** 代表从开始到结束的一次完整智能体执行。每个追踪都有一个唯一的 `trace_id`，用于将所有相关操作组合在一起。

### 跨度 (Span)
一个 **跨度** 是该执行中的单个操作。跨度形成父子层次结构：

每个跨度捕获：
- **发生了什么**: 操作名称（例如，`agent.run`、`model.response`）
- **何时发生**: 开始和结束时间戳
- **上下文**: 输入参数、输出、token使用量
- **关系**: 父跨度、子跨度
- **元数据**: 智能体ID、会话ID、运行ID

## 追踪的内容

Agno自动捕获：

| 操作          | 追踪内容                                                                 |
|--------------------|---------------------------------------------------------------------------------|
| **智能体运行**     | 每次 `agent.run()` 或 `agent.arun()` 调用及其完整上下文                    |
| **模型调用**    | LLM交互，包括提示、响应和token使用量                  |
| **工具执行**| 工具调用及其参数和结果                                     |
| **团队操作**| 团队协调和成员智能体运行                                         |
| **工作流操作**| 即将推出！                                        |

## 主要特性

- **零代码检测**: 无需修改您的智能体代码
- **数据库存储**: 追踪数据存储在您的Agno数据库中（SQLite、PostgreSQL等）
- **灵活查询**: 按智能体、会话、运行或时间范围过滤
- **OpenTelemetry标准**: 导出到Arize Phoenix、Langfuse等外部工具
- **非阻塞**: 追踪永远不会减慢您的智能体
- **可配置**: 根据您的需求调整批处理大小和处理方式

## 快速开始

<Steps>
  <Step title="安装依赖">
    ```bash
    pip install -U opentelemetry-api opentelemetry-sdk openinference-instrumentation-agno
    ```
  </Step>

  <Step title="启用追踪">
    ```python
    from agno.tracing import setup_tracing
    from agno.db.sqlite import SqliteDb

    db = SqliteDb(db_file="tmp/traces.db")
    setup_tracing(db=db) # 在启动时调用一次
    ```
  </Step>

  <Step title="运行您的智能体">
    ```python
    from agno.agent import Agent
    from agno.models.openai import OpenAIChat

    agent = Agent(
        name="My Agent",
        model=OpenAIChat(id="gpt-4o-mini"),
        instructions="You are a helpful assistant",
    )

    agent.run("Hello!")  # 自动追踪！
    ```
  </Step>

  <Step title="查询追踪">
    ```python
    traces, total = db.get_traces(agent_id=agent.id, limit=10)
    for trace in traces:
        print(f"{trace.name}: {trace.duration_ms}ms")
    ```
  </Step>
</Steps>
