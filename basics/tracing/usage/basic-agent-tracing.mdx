此示例展示了如何为智能体启用追踪。一旦启用了追踪，所有智能体运行、模型调用和工具执行都会自动捕获并存储在您的数据库中。

<Steps>

  <Step title="创建Python文件">
    ```bash
    touch basic_agent_tracing.py
    ```
  </Step>

  <Step title="将以下代码添加到您的Python文件中">
    ```python basic_agent_tracing.py
    from agno.agent import Agent
    from agno.db.sqlite import SqliteDb
    from agno.models.openai import OpenAIChat
    from agno.tools.hackernews import HackerNewsTools
    from agno.tracing import setup_tracing

    # 设置追踪数据库
    db = SqliteDb(db_file="tmp/traces.db")

    # 启用追踪（在启动时调用一次）
    setup_tracing(db=db)

    # 创建智能体 - 自动被追踪！
    agent = Agent(
        name="HackerNews Agent",
        model=OpenAIChat(id="gpt-5-mini"),
        tools=[HackerNewsTools()],
        instructions="You are a hacker news agent. Answer questions concisely.",
        markdown=True,
        db=db,
    )

    # 运行智能体 - 追踪数据会自动捕获
    agent.print_response("What's trending on HackerNews?")

    # 从数据库查询追踪数据
    traces, count = db.get_traces(agent_id=agent.id, limit=10)
    print(f"\nFound {count} traces for agent '{agent.name}'")
    for trace in traces:
        print(f"  - {trace.name}: {trace.duration_ms}ms ({trace.status})")
    ```
  </Step>

  <Snippet file="create-venv-step.mdx" />

  <Step title="安装库">
    ```bash
    pip install -U openai agno opentelemetry-api opentelemetry-sdk openinference-instrumentation-agno
    ```
  </Step>

  <Step title="导出您的OpenAI API密钥">
    <CodeGroup>
    ```bash Mac/Linux
    export OPENAI_API_KEY="your_openai_api_key_here"
    ```

    ```bash Windows
    $Env:OPENAI_API_KEY="your_openai_api_key_here"
    ```
    </CodeGroup>
  </Step>

  <Step title="运行智能体">
    <CodeGroup>
    ```bash Mac
    python basic_agent_tracing.py
    ```

    ```bash Windows
    python basic_agent_tracing.py
    ```
    </CodeGroup>
  </Step>

</Steps>
