此示例展示了如何为团队启用追踪。当启用了追踪后，所有团队操作、成员智能体运行、模型调用和工具执行都会自动捕获并存储在您的数据库中。

<Steps>

  <Step title="创建Python文件">
    ```bash
    touch basic_team_tracing.py
    ```
  </Step>

  <Step title="将以下代码添加到您的Python文件中">
    ```python basic_team_tracing.py
    from agno.agent import Agent
    from agno.db.sqlite import SqliteDb
    from agno.models.openai import OpenAIChat
    from agno.team import Team
    from agno.tools.hackernews import HackerNewsTools
    from agno.tracing import setup_tracing

    # 设置追踪数据库
    db = SqliteDb(db_file="tmp/traces.db")

    # 启用追踪（在启动时调用一次）
    setup_tracing(db=db)

    # 创建成员智能体 - 无需在每个智能体上单独设置追踪！
    hackernews_agent = Agent(
        name="HackerNews Agent",
        model=OpenAIChat(id="gpt-5-mini"),
        tools=[HackerNewsTools()],
        instructions="You are a hacker news agent. Answer questions concisely.",
        markdown=True,
    )

    # 创建包含该智能体作为成员的团队
    team = Team(
        name="HackerNews Team",
        model=OpenAIChat(id="gpt-5-mini"),
        members=[hackernews_agent],
        instructions="You are a hacker news team. Use the HackerNews Agent to answer questions.",
        db=db,
    )

    # 运行团队 - 追踪数据会自动捕获
    team.print_response("What's trending on HackerNews?")

    # 从数据库查询追踪数据
    traces, count = db.get_traces(team_id=team.id, limit=10)
    print(f"\nFound {count} traces for team '{team.name}'")
    for trace in traces:
        print(f"  - {trace.name}: {trace.duration_ms}ms ({trace.status})")
    ```
  </Step>

    ```
    </CodeGroup>
  </Step>

  <Step title="运行团队">
    <CodeGroup>

    ```

    ```bash Windows
    python basic_team_tracing.py
    ```
    </CodeGroup>
  </Step>
