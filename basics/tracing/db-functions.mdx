Agno在您的数据库实例上提供了便捷函数来查询追踪和跨度。这些函数适用于任何支持的数据库（SQLite、PostgreSQL等）。

## 追踪函数

### `db.get_trace()`

通过标识符获取单个追踪。

```python
# 通过trace_id获取
trace = db.get_trace(trace_id="abc123...")

# 通过run_id获取（返回最近的匹配项）
trace = db.get_trace(run_id=response.run_id)
```

**参数:**

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `trace_id` | `Optional[str]` | 唯一的追踪标识符 |
| `run_id` | `Optional[str]` | 按运行ID过滤 |

**返回值:** `Trace` 或 `None`

有关更多信息，请参阅[Trace](/reference/tracing/trace)参考文档。

### `db.get_traces()`

获取多个追踪，支持过滤和分页。

```python
# 获取最近的追踪
traces, total_count = db.get_traces(limit=20)

# 按智能体过滤
traces, count = db.get_traces(agent_id=agent.id)

# 按时间范围过滤
from datetime import datetime, timedelta, timezone

now = datetime.now(timezone.utc)
traces, count = db.get_traces(
    start_time=now - timedelta(hours=1),
    end_time=now,
    limit=100
)
```

**参数:**

| 参数 | 类型 | 默认值 | 描述 |
|-----------|------|---------|-------------|
| `run_id` | `Optional[str]` | `None` | 按运行ID过滤 |
| `session_id` | `Optional[str]` | `None` | 按会话ID过滤 |
| `user_id` | `Optional[str]` | `None` | 按用户ID过滤 |
| `agent_id` | `Optional[str]` | `None` | 按智能体ID过滤 |
| `team_id` | `Optional[str]` | `None` | 按团队ID过滤 |
| `workflow_id` | `Optional[str]` | `None` | 按工作流ID过滤 |
| `status` | `Optional[str]` | `None` | 按状态过滤 (`OK`, `ERROR`, `UNSET`) |
| `start_time` | `Optional[datetime]` | `None` | 过滤此时间之后的追踪 |
| `end_time` | `Optional[datetime]` | `None` | 过滤此时间之前的追踪 |
| `limit` | `Optional[int]` | `20` | 返回的最大追踪数量 |
| `page` | `Optional[int]` | `1` | 分页的页码 |

**返回值:** `tuple[List[Trace], int]` - (追踪列表, 总数量)

## 跨度函数

### `db.get_span()`

通过ID获取单个跨度。

```python
span = db.get_span(span_id="xyz789...")
if span:
    print(f"{span.name}: {span.duration_ms}ms")
```

**参数:**

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `span_id` | `str` | 唯一的跨度标识符 |

**返回值:** `Span` 或 `None`

有关更多信息，请参阅[Span](/reference/tracing/span)参考文档。

### `db.get_spans()`

获取追踪或父级的多个跨度。

```python
# 获取追踪中的所有跨度
spans = db.get_spans(trace_id=trace.trace_id)

# 获取特定父级的子跨度
children = db.get_spans(parent_span_id=root_span.span_id)
```

**参数:**

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `trace_id` | `Optional[str]` | 按追踪ID过滤 |
| `parent_span_id` | `Optional[str]` | 按父跨度ID过滤 |

**返回值:** `List[Span]`

<Note>
  与`get_traces()`不同，`get_spans()`返回一个不包含计数的列表。
</Note>

## 示例：分析一次运行

```python
from agno.db.sqlite import SqliteDb

db = SqliteDb(db_file="tmp/traces.db")

# 获取运行的追踪
trace = db.get_trace(run_id=response.run_id)

if trace:
    print(f"追踪: {trace.name} ({trace.duration_ms}ms)")

    # 获取所有跨度
    spans = db.get_spans(trace_id=trace.trace_id)

    # 打印执行树
    for span in sorted(spans, key=lambda s: s.start_time):
        indent = "  " if span.parent_span_id else ""
        print(f"{indent}- {span.name} ({span.duration_ms}ms)")
```
