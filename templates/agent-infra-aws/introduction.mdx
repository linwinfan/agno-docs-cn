Agent Infra AWS 模板为在 AWS 上运行 AgentOS 提供了标准化的代码库。该模板使用 `agno-infra` SDK 来管理本地和 AWS 部署。

### 本地环境

使用 Docker 运行 AgentOS 和 PostgreSQL。

适用于在部署到云端之前进行开发、测试和验证您的设置。

### AWS 环境

AgentOS 部署在 ECS 上，同时镜像构建并推送到 AWS ECR。

通过 RDS 配置 PostgreSQL 以提供可靠、托管的数据库服务。

该模板使用 agno-infra 自动化基础设施创建和部署步骤。

### 如何开始

- 克隆模板仓库并安装依赖项
- 从本地设置开始，确保端到端的所有功能都能正常工作。
- 一旦本地环境准备就绪，使用提供的指南迁移到 AWS 部署。
