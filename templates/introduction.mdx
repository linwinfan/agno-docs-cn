在构建 AgentOS 的生产实例时，您需要在自己的云环境中托管 AgentOS 并连接到 os.agno.com。

# 什么是模板？

**模板是用于生产环境 AgentOS 的标准化代码库。** 它们包含：

- 使用 FastAPI 的 AgentOS 实例
- 用于存储会话、记忆和知识的 PostgreSQL 数据库

模板设置为使用 Docker 在本地运行，并可轻松部署到 AWS。它们是绝佳的起点，也是我们为客户使用的解决方案。您肯定需要根据自己的特定需求进行自定义，但它们会让您更快地开始。

它们包含多年的经验积累，向开源社区免费提供。

# 工作原理

- 使用 `ag infra create` 创建代码库
- 使用 Docker 在本地运行：`ag infra up`
- 在 AWS 上运行：`ag infra up prd:aws`

我们建议从 `agent-infra-docker` 模板开始，然后逐步扩展。
