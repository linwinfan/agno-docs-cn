## 在 Docker 上运行 Jupyter

Jupyter notebook 是 AI 开发的必备工具。更新 `resources.py` 文件为：

```python resources.py
from os import getenv

from agno.docker.app.jupyter import Jupyter
from agno.docker.app.postgres import PgVectorDb
from agno.docker.resources import DockerResources

# -*- PgVector 在端口 5432:5432 上运行
vector_db = PgVectorDb(
    pg_user="ai",
    pg_password="ai",
    pg_database="ai",
    debug_mode=True,
)

# -*- Jupyter 在端口 8888:8888 上运行
jupyter = Jupyter(
    mount_workspace=True,
    env_vars={"OPENAI_API_KEY": getenv("OPENAI_API_KEY")},
)

# -*- DockerResources
dev_docker_resources = DockerResources(
    apps=[vector_db, jupyter],
)
```

使用以下命令启动资源：

<CodeGroup>

```bash Mac
ag start resources.py
```

```bash Windows
ag start resources.py
```

</CodeGroup>

### 查看 Jupyterlab UI

- 打开 localhost:8888 查看 Jupyterlab UI。密码：**admin**
- 目录在笔记本中自动挂载。

## 停止资源

<CodeGroup>

```bash Mac
ag stop resources.py
```

```bash Windows
ag stop resources.py
```

</CodeGroup>
