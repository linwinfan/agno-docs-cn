Agent Infra Docker 模板提供了一个简单的 Docker Compose 文件，用于在本地运行 AgentOS。

### 本地环境

使用 Docker 运行 AgentOS 和 PostgreSQL。

非常适合在部署到云端之前进行开发、测试和验证您的设置。

### 生产环境

由于此模板为您提供 Dockerfile 和 Docker Compose 文件，您可以轻松部署到任何支持 Docker 的云提供商。或者您可以部署到托管平台，如 [Railway](https://railway.app/) 或 [Render](https://render.com/)。对于 Railway，您可以使用 [Agent Infra Railway 模板](/templates/agent-infra-railway/introduction) 来部署您的 AgentOS。

### 如何开始

- 克隆模板仓库并安装依赖项
- 从本地设置开始，确保端到端的一切正常工作。
- 一旦本地环境准备就绪，使用提供的指南转移到您选择的云提供商。
