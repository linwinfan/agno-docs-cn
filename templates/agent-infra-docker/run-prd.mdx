---
title: "在生产环境中运行 Agent Infra Docker"
sidebarTitle: 生产环境运行
---

Agent Infra Docker 模板提供了生产就绪的 Docker Compose 配置和 Dockerfile，旨在跨各种基础架构环境可靠地部署 AgentOS。作为标准容器化系统打包，它提供完全的灵活性，在任何支持容器的地方运行。

例如，您可以将其部署到以下云提供商：

- [AWS ECS](https://aws.amazon.com/ecs/)
- [Google Cloud Compute Engine](https://cloud.google.com/compute-engine/)
- [Azure 虚拟机](https://azure.microsoft.com/zh-cn/products/virtual-machines/)

或以下平台：

- [Modal](https://modal.com/)
- [Render](https://render.com/)
- [DigitalOcean](https://digitalocean.com/)
- [Fly.io](https://fly.io/)

此模板为您提供在任何您选择的基础架构上部署 AgentOS 的自由。

对于专门构建的、针对 AWS 优化的部署，请参阅 [Agent Infra AWS 模板](/templates/agent-infra-aws/introduction)，它演示了如何在 AWS 上使用 ECS 将 AgentOS 投入生产。或者，对于简单快速的部署方法，请参阅 [Agent Infra Railway 模板](/templates/agent-infra-railway/introduction)，它演示了如何在 Railway 上将 AgentOS 投入生产。
