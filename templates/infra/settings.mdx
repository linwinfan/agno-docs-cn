`InfraSettings` 对象通常在 `infra/settings.py` 文件中定义，用于定义应用程序和资源使用的通用设置。

它不是强制性的，除了保存工作区应用程序和资源使用的配置外，没有其他用途。`InfraSettings` 对象中的值也可以使用环境变量或 `.env` 文件进行设置。

## 示例

`agent-infra-aws` 模板使用的 `InfraSettings` 示例。在 [github](https://github.com/agno-agi/agent-infra-aws/blob/main/infra/settings.py) 上查看此文件

```python infra/settings.py
from pathlib import Path

from agno.infra.settings import InfraSettings

#
# -*- 使用 InfraSettings 对象定义基础设施设置
# 这些值也可以使用环境变量或 .env 文件进行设置
#
infra_settings = InfraSettings(
    # 基础设施名称：用于命名资源
    infra_name="ai",
    # 基础设施根目录路径
    infra_root=Path(__file__).parent.parent.resolve(),
    # -*- 开发设置
    dev_env="dev",
    # -*- 开发应用程序
    dev_app_enabled=True,
    dev_api_enabled=True,
    dev_db_enabled=True,
    # dev_jupyter_enabled=True,
    # -*- 生产设置
    prd_env="prd",
    # -*- 生产应用程序
    prd_app_enabled=True,
    prd_api_enabled=True,
    prd_db_enabled=True,
    # -*- AWS 设置
    # AWS 资源的区域
    aws_region="us-east-1",
    # AWS 资源的可用区
    aws_az1="us-east-1a",
    aws_az2="us-east-1b",
    # aws_region 中的子网 ID
    # subnet_ids=["subnet-xyz", "subnet-xyz"],
    #
    # -*- 镜像设置
    #
    # 镜像的默认仓库
    image_repo="agno"
    # 在本地构建镜像
    build_images=False
    # 构建后推送镜像
    push_images=False
    # 构建镜像时跳过缓存
    skip_image_cache=False
    # 强制拉取 FROM 中的镜像
    force_pull_images=False
)
```

## 用法

使用基础设施设置来

- 命名资源
- 使用 `infra_settings.infra_root` 获取基础设施根目录路径

```python dev_resources.py
...
# -*- 在端口 8501:8501 上运行的 Streamlit
dev_streamlit = Streamlit(
    name=f"{infra_settings.dev_key}-app",
    enabled=infra_settings.dev_app_enabled,
    ...
    # 从 secrets/dev_app_secrets.yml 读取密钥
    secrets_file=infra_settings.infra_root.joinpath("infra/secrets/dev_app_secrets.yml")
)
```

- 保存 AWS 常量，如 `可用区` 和 `子网`

```python prd_resources.py
# -*- 在 ECS 上运行的 FastAPI
prd_fastapi = FastApi(
    name=f"{infra_settings.prd_key}-api",
    enabled=infra_settings.prd_api_enabled,
    ...
    subnets=infra_settings.subnet_ids,
    ...
)

# -*- RDS 数据库实例
prd_db = DbInstance(
    name=f"{infra_settings.prd_key}-db",
    enabled=infra_settings.prd_db_enabled,
    ...
    availability_zone=infra_settings.aws_az1,
    ...
)
```
