Agent Infra Railway 模板为运行 AgentOS 提供了一个简单的 Railway 项目。

### 本地环境

使用 Docker Desktop 运行 AgentOS 和 PostgreSQL。

适用于在部署到云端之前进行开发、测试和验证您的设置。

### 生产环境

使用 Dockerfile 在 Railway 上部署 AgentOS，并使用 PgVector 模板作为数据库

该模板使用单个脚本自动化基础设施创建和部署步骤。

### 如何开始

- 克隆模板仓库并安装依赖项
- 从本地设置开始，确保端到端的所有功能都能正常工作。
- 一旦本地环境准备就绪，使用提供的指南迁移到 Railway 部署。
